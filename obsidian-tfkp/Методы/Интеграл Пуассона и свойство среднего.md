# Интеграл Пуассона и свойство среднего

> [!abstract] Коротко
> Значение гармонической функции в центре круга — среднее по окружности; в любой точке круга — среднее по окружности с весом ядра Пуассона. Это даёт явное решение задачи Дирихле в круге, характеризацию гармонических функций и формулу Йенсена.

## Инструмент
**Теорема о среднем (Предл. 14.2).** Если $h\in\operatorname{Harm}(B(a,R))\cap C(\overline{B(a,R)})$, то при $0<r\le R$
$$h(a)=\frac1{2\pi}\int_0^{2\pi}h(a+re^{i\vartheta})\,d\vartheta .$$
*Доказательство:* $h=\operatorname{Re}f$, $f\in H(B(a,R))$ (односвязность), и берём вещественную часть формулы Коши; $r=R$ — равномерная непрерывность. В частности, это верно для $\ln|F|=\operatorname{Re}\operatorname{Log}F$, если $F$ голоморфна без нулей.

**Ядро Пуассона (Лемма 24.6).** Для $z=re^{i\varphi}$, $\zeta=Re^{i\vartheta}$, $\psi=\vartheta-\varphi$:
$$P(z,\zeta)=\frac1{2\pi R}\frac{R^2-|z|^2}{|\zeta-z|^2},\qquad \frac12+\sum_{n\ge1}\Bigl(\frac rR\Bigr)^n\cos n\psi=\frac12\operatorname{Re}\frac{\zeta+z}{\zeta-z}=\pi P_r(\psi);$$
$P_r>0$, $\int_{-\pi}^{\pi}P_r=1$, и $P_r\to0$ равномерно на $\delta\le|\psi|\le\pi$ при $r\to R-$ (аппроксимативная единица); $P(\cdot,\zeta)$ гармонична как $\operatorname{Re}$ голоморфной функции.

**Теорема 24.7 (формула Пуассона).** Для $h_0\in C(C_R)$ функция $h(z)=\int_{C_R}P(z,\zeta)h_0(\zeta)\,|d\zeta|$ гармонична в $B_R$ и непрерывно продолжается на $\overline{B_R}$ значениями $h_0$.

**Обращение (Теорема 22.6).** Непрерывная функция со (локальным) свойством среднего гармонична.

## Схема применения
1. *Свойство среднего* $\Rightarrow$ интегральное тождество для значения в центре (или для $\ln|f|$ после деления на множители Бляшке).
2. *Решение задачи Дирихле в круге:* записать кандидата интегралом Пуассона; гармоничность — под знаком интеграла ($\operatorname{Re}\frac{\zeta+z}{\zeta-z}$).
3. *Граничные значения:* $h(z)-h_0(\zeta_0)=\int P(z,\zeta)\bigl(h_0(\zeta)-h_0(\zeta_0)\bigr)|d\zeta|$; разбить окружность на дугу около $\zeta_0$ (мала разность $h_0$) и остальное (мало ядро).
4. *Характеризация:* если $u$ имеет свойство среднего, сравнить с интегралом Пуассона $H$ тех же граничных данных: $u-H$ имеет свойство среднего и нулевые граничные значения, по [[Принцип максимума|принципу максимума]] $u=H$.
5. Для других областей — перенос [[Принцип соответствия границ|конформным отображением]] на круг.

## Типичные применения и тонкости
- [[Б-21 Гармонические функции. Среднее и принцип максимума|Б-21]]: теорема о среднем, принцип максимума; [[Б-22 Задача Дирихле. Метод конформного отображения. Теорема Лебега|Б-22]]: метод конформного отображения ($h=H\circ\varphi$), гармоничность функций со свойством среднего; решение в полуплоскости $\frac1\pi\int\frac{y\,h_0(t)}{(t-x)^2+y^2}dt$.
- [[Б-24 Метод Фурье и формула Пуассона|Б-24]]: формула Пуассона как сумма ряда Фурье решения; свойства ядра.
- [[Б-00 Предварительные сведения и глава 12|Б-00]], [[Б-35 Показатель сходимости нулей и порядок|Б-35]]: формула Йенсена — теорема о среднем для $\ln|f/B|$; [[Б-00 Предварительные сведения и глава 12|Б-00]]: $A(R)>0$ в лемме Бореля–Каратеодори из нулевого среднего $\operatorname{Re}f$.
- Тонкость: среднее для $\ln|f|$ верно лишь при отсутствии нулей $f$ в замкнутом круге; иначе появляется вклад нулей ([[Формула Йенсена]]). Без односвязности задача Дирихле может быть неразрешима ($\mathbb D\setminus\{0\}$).
