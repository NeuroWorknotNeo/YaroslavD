# Равенство Парсеваля и оценки в L²

> [!abstract] Коротко
> Среднее квадрата модуля голоморфной функции по окружности равно сумме квадратов модулей тейлоровских коэффициентов. Так интегральные (в среднем) оценки превращаются в оценки коэффициентов и обратно; вместе с неравенством Коши–Буняковского это даёт оценки длин через площади.

## Инструмент
**Равенство Парсеваля (формула (16.1)).** Если $g(z)=\sum_{n\ge0}b_nz^n$ голоморфна в $B(0,R)$, то при $0\le r<R$
$$\frac1{2\pi}\int_0^{2\pi}|g(re^{it})|^2\,dt=\sum_{n\ge0}|b_n|^2r^{2n}.$$
*Доказательство:* ряд $\sum b_nr^ne^{int}$ сходится равномерно по $t$; умножаем на сопряжённый ряд и интегрируем почленно, используя $\frac1{2\pi}\int_0^{2\pi}e^{i(n-m)t}\,dt=\delta_{nm}$. То же для лорановских рядов в кольце.

**Формулы для коэффициентов.** $c_n=\dfrac1{2\pi r^n}\int_0^{2\pi}g(re^{it})e^{-int}\,dt$, откуда $|c_n|\le\dfrac1{2\pi r^n}\int_0^{2\pi}|g(re^{it})|\,dt$ (оценка через $L^1$-среднее, сильнее [[Неравенства Коши для коэффициентов|неравенств Коши]]). Для вещественной части: $\int_0^{2\pi}\operatorname{Re}g\cdot e^{-int}\,dt=\pi c_nr^n$ при $n\ge1$.

**Коши–Буняковский.** $\Bigl(\int_a^b\varphi\psi\Bigr)^2\le\int_a^b\varphi^2\int_a^b\psi^2$; типично $|f'|=\frac1{\sqrt r}\cdot\sqrt r|f'|$ или $|h'|=1\cdot|h'|$.

## Схема применения
1. Записать интересующую величину как интеграл по окружности от $|g|^2$ (или от $g\,e^{-int}$).
2. По Парсевалю перейти к сумме по коэффициентам (или обратно).
3. Оценить с другой стороны: через максимум модуля ($\sum|b_n|^2r^{2n}\le M(r)^2$), через площадь образа ($\pi\sum n|b_n|^2\rho^{2n}$), через знак $\operatorname{Re}$.
4. Для оценок «длина через площадь» — Коши–Буняковский по окружности/радиусу и интегрирование по второму полярному переменному.

## Типичные применения и тонкости
- [[Б-00 Предварительные сведения и глава 12|Б-00]]: альтернативное доказательство леммы Шварца и случая равенства: $|g(z_0)|=1$ и $\frac1{2\pi}\int|g|^2=1+\sum_{n\ge1}|d_n|^2s^{2n}\le1$ дают $d_n=0$.
- [[Б-12 Теорема площадей|Б-12]]: вычисление $m_2(G_r)$ через произведение рядов Фурье; [[Б-16 Радиальные пределы почти всюду|Б-16]]: площадь образа круга $\pi\sum n|b_n|^2\rho^{2n}$ и оценка $\int_0^{2\pi}\bigl(\int_{1/2}^1|f'|\,dr\bigr)^2dt\le\ln2\cdot m_2(G)$.
- [[Б-41д Оценка Литтлвуда|Б-41д]]: оценка $\sum|c_n|^2r^{2n}\le\frac{r^2}{1-r^2}$ для корневого преобразования и затем $|a_n|<en$ через $L^1$-среднее; [[Б-36 Теорема Адамара о факторизации|Б-36]]: Лемма 16.6 $|b_n|\le\frac{2(A-\operatorname{Re}f(0))}{R^n}$ при $\operatorname{Re}f\le A$.
- [[Б-23 Разложение по однородным гармоническим многочленам|Б-23]]: оценка голоморфной функции через вещественную часть, $|c_n|\le\frac{2M}{R^n}$; [[Б-18 Локально связные границы. Теорема Каратеодори о непрерывном продолжении|Б-18]]: лемма Вольфа.
- Тонкость: для почленного интегрирования нужна равномерная сходимость ряда на окружности, т.е. $r$ строго меньше радиуса сходимости; переход $r\to1$ — монотонной сходимостью.
