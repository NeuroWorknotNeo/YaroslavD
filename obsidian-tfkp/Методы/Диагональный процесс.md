# Диагональный процесс

> [!abstract] Коротко
> Чтобы из последовательности выделить подпоследовательность, сходящуюся сразу в счётном множестве точек, выделяют вложенные подпоследовательности для каждой точки по очереди и берут «диагональ» — $n$-й член $n$-й подпоследовательности.

## Инструмент
**Лемма (диагональ).** Пусть $A=\{a_1,a_2,\dots\}$ счётно и последовательность $(f_n)$ ограничена в каждой точке $A$: $\sup_n|f_n(a_p)|<\infty$. Тогда существует подпоследовательность $(f_{m_n})$, сходящаяся в каждой точке $A$.

*Доказательство (через возрастающие отображения индексов).* Подпоследовательность задаётся строго возрастающим $N:\mathbb N\to\mathbb N$; для него $N(k)\ge k$.
- *Шаг 1.* По Больцано–Вейерштрассу найдётся $N_1$ с сходящейся $(f_{N_1(k)}(a_1))_k$.
- *Шаг $p$.* Последовательность $(f_{N_{p-1}(k)}(a_p))_k$ ограничена; выбираем возрастающее $\sigma_p$ с её сходимостью вдоль $\sigma_p$ и полагаем $N_p=N_{p-1}\circ\sigma_p$. Тогда $(f_{N_p(k)}(a_l))_k$ сходится при всех $l\le p$.
- *Диагональ.* $m_n:=N_n(n)$. Возрастание: $m_{n+1}=N_n(\sigma_{n+1}(n+1))\ge N_n(n+1)>N_n(n)=m_n$. При $n\ge p$ имеем $N_n=N_p\circ\sigma_{p+1}\circ\dots\circ\sigma_n$, т.е. $m_n=N_p(k_n)$ с возрастающими $k_n$; значит $(f_{m_n}(a_p))_{n\ge p}$ — подпоследовательность сходящейся последовательности.

## Схема применения
1. Выбрать счётное всюду плотное множество $A$ (в области — $(\mathbb Q+i\mathbb Q)\cap D$) и проверить поточечную ограниченность в его точках.
2. Построить вложенные подпоследовательности $N_1\supset N_2\supset\dots$, сходящиеся в $a_1$, затем в $a_1,a_2$ и т.д.
3. Взять диагональ $m_n=N_n(n)$: она сходится во всех точках $A$.
4. Перейти от сходимости на $A$ к локально равномерной сходимости с помощью равностепенной непрерывности (Лемма 13.1, $3\varepsilon$-рассуждение).

## Типичные применения и тонкости
- [[Б-09 Компактность семейства. Теорема Монтеля|Б-09]]: доказательство теоремы Арцела–Асколи и, как следствие, теоремы Монтеля (см. [[Нормальные семейства (Монтель, Арцела–Асколи)]]).
- [[Б-10 Теорема Римана — существование однолистной функции в круг|Б-10]]: через теорему Монтеля — существование экстремальной функции в теореме Римана.
- Тонкость: диагональ сходится в точке $a_p$ лишь начиная с номера $n=p$ — конечное число первых членов не влияет на сходимость. Сама диагональ даёт только поточечную сходимость на счётном множестве; равномерность на компактах обеспечивает уже равностепенная непрерывность.
