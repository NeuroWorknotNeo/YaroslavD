# Ряды Фурье

> [!abstract] Коротко
> На окружности $|z|=r$ степенной (или лорановский) ряд — это ряд Фурье по $e^{in\vartheta}$. Ортогональность экспонент позволяет вычислять коэффициенты интегралами, перемножать ряды и находить средние; гармоническая функция в круге раскладывается по $r^n\cos n\varphi$, $r^n\sin n\varphi$.

## Инструмент
**Ортогональность.** $\frac1{2\pi}\int_0^{2\pi}e^{i(n-m)\vartheta}\,d\vartheta=\delta_{nm}$; для вещественной системы $\int_{-\pi}^{\pi}\cos n\vartheta\cos m\vartheta\,d\vartheta=\pi\delta_{nm}$ ($n,m\ge1$) и т.д. Равномерно сходящийся тригонометрический ряд — ряд Фурье своей суммы (Лемма 23.2).

**Разложение гармонической функции (Предл. 14.5).** Если $h\in\operatorname{Harm}(B_{R+\varepsilon})$, то в $\overline{B_R}$
$$h(re^{i\varphi})=\frac{A_0}2+\sum_{n\ge1}r^n(A_n\cos n\varphi+B_n\sin n\varphi),\qquad A_n=\frac1{\pi R^n}\int_{-\pi}^{\pi}h(Re^{i\vartheta})\cos n\vartheta\,d\vartheta,$$
и аналогично $B_n$ с $\sin$; слагаемые $r^n\cos n\varphi=\operatorname{Re}z^n$, $r^n\sin n\varphi=\operatorname{Im}z^n$ — однородные гармонические многочлены (единственные с точностью до линейной комбинации, Лемма 23.1). *Идея:* $h=\operatorname{Re}f$, $f=\sum c_nz^n$, и коэффициенты находятся интегрированием по $C_R$.

**Сходимость ряда Фурье (Теорема 24.4).** Для $2\pi$-периодической $F\in C^1$ ряд Фурье сходится к $F$ в каждой точке (ядро Дирихле + лемма Римана–Лебега для $g(t)=\frac{F(\varphi+t)-F(\varphi)}{\sin(t/2)}$). Для $C^{1+1}$ коэффициенты $O(1/n^2)$ (двукратное интегрирование по частям), и сходимость равномерна.

## Схема применения
1. Записать функцию на окружности $|z|=r$ как ряд по $e^{in\vartheta}$ (из степенного/лорановского ряда или как ряд Фурье граничных данных).
2. Для произведения (например, $\bar g\cdot zg'$) перемножить абсолютно сходящиеся ряды и проинтегрировать: выживают пары частот с суммой $0$.
3. Для коэффициентов — умножить на $e^{-in\vartheta}$ и проинтегрировать; для оценок — оценить подынтегральное выражение.
4. Для построения решения (метод Фурье) — задать $h$ рядом с коэффициентами граничных данных, доказать сходимость (сначала для гладких данных), затем приблизить общие данные и перейти к пределу по [[Принцип максимума|принципу максимума]].

## Типичные применения и тонкости
- [[Б-23 Разложение по однородным гармоническим многочленам|Б-23]]: разложение гармонической функции по однородным гармоническим многочленам; оценка $\|f\|_{\overline{B_r}}\le\frac{R+2r}{R-r}\|h\|_{\overline{B_R}}$ голоморфной функции через её вещественную часть; аналог теоремы Вейерштрасса.
- [[Б-24 Метод Фурье и формула Пуассона|Б-24]]: метод Фурье решения задачи Дирихле в круге и суммирование ряда в формулу Пуассона.
- [[Б-12 Теорема площадей|Б-12]]: площадь $m_2(G_r)$ через произведение рядов Фурье $\overline{g(re^{it})}$ и $zg'(z)$.
- [[Б-36 Теорема Адамара о факторизации|Б-36]]: коэффициенты $g$ через интегралы от $\operatorname{Re}g$ (Лемма 16.6); [[Б-41д Оценка Литтлвуда|Б-41д]]: формула коэффициента через $L^1$-среднее.
- Тонкость: равномерная сходимость ряда Фурье *к самой* функции — содержательный факт (нужна гладкость данных); для непрерывных данных используют приближение гладкими ($T_\delta T_\delta F$) и принцип максимума.

## Билеты, где используется
- [[Б-12 Теорема площадей|Б-12. Теорема площадей]] — перемножение рядов для $\overline{g}$ и $zg'$ на окружности, выживают только пары с нулевой суммой показателей.
- [[Б-23 Разложение по однородным гармоническим многочленам|Б-23. Разложение по однородным гармоническим многочленам]] — ортогональность тригонометрической системы и почленное интегрирование: коэффициенты (14.2), (14.3) — коэффициенты Фурье $h(Re^{i\vartheta})$.
- [[Б-24 Метод Фурье и формула Пуассона|Б-24. Метод Фурье и формула Пуассона]] — коэффициенты Фурье данных, двукратное интегрирование по частям, ядро Дирихле и лемма Римана–Лебега: ряд Фурье гладкой $H_0$ сходится к $H_0$.
