Подробный разбор трёх заданий практикума.

praktikum.pdf  -- готовый документ (54 страницы):
                  задание 1 (обращение матрицы, MPI),
                  задание 2 (приближение функций одной переменной, Qt),
                  задание 3 (функция двух переменных, формула Ньютона, Qt+3D).
                  Для каждого задания: постановка, полная математика с выводом
                  формул, разбор кода, таблицы измерений, вопросы на защите
                  с ответами и полные тексты файлов с методами.

praktikum.tex  -- исходник. Пересобрать:
                  pdflatex praktikum.tex && pdflatex praktikum.tex
                  (нужны пакеты texlive-latex-recommended, texlive-lang-cyrillic,
                   в Ubuntu: sudo apt install texlive-latex-extra texlive-lang-cyrillic)
                  Второй прогон нужен, чтобы собралось оглавление.
                  Картинки берутся из ../task2_yarik и ../task3_yarik.
