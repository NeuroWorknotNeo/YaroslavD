# О-01. Задача Коши для уравнения 2-го порядка. Характеристики

> [!question] Формулировка билета
> Сформулировать задачу Коши для линейного уравнения с частными производными второго порядка. Переход к задаче с «начальными данными» на плоскости $y_n=0$. Понятие характеристики. Разобрать пример задачи Коши с данными на характеристике.

**Где в конспекте:** ч. 1, лекция 1 (с. 6–11), пример — лекция 2 (с. 14).

## Кратко (план ответа)
- Оператор $Lu=\sum a_{ij}(x)u_{x_ix_j}+\sum b_iu_{x_i}+cu$, данные $u|_S=u_0$, $\partial_\nu u|_S=u_1$ на поверхности $S$ класса $C^2$.
- Локальная замена переменных выпрямляет $S$ в кусок плоскости $\{y_n=0\}$; уравнение сохраняет вид, меняются коэффициенты.
- Из данных находятся все производные на $S$, кроме $u_{y_ny_n}$; её можно выразить из уравнения, только если коэффициент при ней $\ne0$.
- Характеристика: $\sum a_{ij}\nu_i\nu_j=0$ на $S$ — тогда старшую производную выразить нельзя, данные связаны условием совместности.
- Пример: данные на характеристике — задача либо неразрешима, либо имеет бесконечно много решений.

---

## Определения

**Линейный оператор второго порядка.** Пусть $\Omega\subseteq\mathbb R^n$ — область.
$$L:C^2(\Omega)\to C(\Omega),\qquad Lu=\sum_{i,j=1}^na^{ij}(x)u_{x_ix_j}+\sum_{i=1}^na^i(x)u_{x_i}+a(x)u,$$
$a^{ij},a^i,a\in C(\Omega)$, матрица $A=(a^{ij})$ не равна нулю ни в одной точке. Матрицу можно считать симметричной: $A=Q+R$, $Q=\frac{A+A^{t}}2$, $R=\frac{A-A^t}2$, и $\sum r^{ij}u_{x_ix_j}=0$ из-за $u_{x_ix_j}=u_{x_jx_i}$ и $r^{ij}=-r^{ji}$.

**Уравнение:** $Lu=f$ в $\Omega$. (1.1)

**Поверхность класса $C^2$.** $S$ — $(n-1)$-мерная поверхность класса $C^2$, если для любой $x_0\in S$ есть окрестность $U(x_0)$ и $C^2$-диффеоморфизм $U(x_0)\to V(0)$, переводящий $S\cap U$ в $\{y_n=0\}\cap V$. По теореме о неявной функции локально $S=\{F(x)=0\}$, $F\in C^2$, $\nabla F\ne0$ на $S$.

**Задача Коши.** На $S$ задан единичный вектор $\xi(x)$, не касающийся $S$, и функции $u_0,u_1$. Найти $u\in C^2(\Omega)$:
$$Lu=f,\qquad u\big|_S=u_0,\qquad \frac{\partial u}{\partial\xi}\Big|_S=u_1,\qquad \frac{\partial u}{\partial\xi}=\sum_i\xi^iu_{x_i}.\qquad(1.1)\text{–}(1.3)$$
Функции $a^{ij},a^i,a,\xi,f,u_0,u_1,S$ — данные задачи.

**Характеристика.** Пусть $S=\{F=0\}$ около $x_0$, $\nabla F\ne0$. Точка $x_0$ называется *характеристической* для (1.1), если
$$\bigl(A(x_0)\nabla F(x_0),\nabla F(x_0)\bigr)=0 .$$
Если это верно во всех точках $S$, поверхность $S$ называется *характеристикой*.

## Переход к данным на плоскости $y_n=0$

Фиксируем $x_0\in S$, $S\cap U(x_0)=\{F=0\}$, пусть $F_{x_n}\ne0$. Диффеоморфизм
$$\Phi:\ y_1=x_1-x_{01},\ \dots,\ y_{n-1}=x_{n-1}-x_{0,n-1},\ y_n=F(x),\qquad J=\det\Phi'=F_{x_n}\ne0,$$
переводит $S\cap U$ в $\Sigma=\{y_n=0\}\cap V(0)$. Положим $v(y)=u(\Phi^{-1}(y))$. По цепному правилу
$$u_{x_j}=\sum_kv_{y_k}\frac{\partial\Phi_k}{\partial x_j},\qquad u_{x_ix_j}=\sum_{k,l}v_{y_ky_l}\frac{\partial\Phi_k}{\partial x_i}\frac{\partial\Phi_l}{\partial x_j}+\sum_kv_{y_k}\frac{\partial^2\Phi_k}{\partial x_i\partial x_j}.\qquad(1.4)$$
Подставляя в (1.1), получаем уравнение того же вида
$$\sum_{k,l}b^{kl}v_{y_ky_l}+\sum_kb^kv_{y_k}+bv=g,\qquad b^{kl}=\sum_{i,j}a^{ij}\frac{\partial\Phi_k}{\partial x_i}\frac{\partial\Phi_l}{\partial x_j},$$
и, главное,
$$b^{nn}=\sum_{i,j}a^{ij}F_{x_i}F_{x_j}=(A\nabla F,\nabla F).\qquad(1.5)$$
Начальные условия: $v|_{y_n=0}=v_0(\hat y)$, где $\hat y=(y_1,\dots,y_{n-1})$ (1.6). Поскольку $\partial_\xi u=\sum_kv_{y_k}\partial_\xi\Phi_k$ и $\partial_\xi\Phi_n=(\nabla F,\xi)\ne0$ ($\xi$ не касается $S$, $\nabla F$ — нормаль), второе условие переписывается как
$$v_{y_n}\big|_{y_n=0}=\Bigl(\frac{\partial\Phi_n}{\partial\xi}\Bigr)^{-1}\Bigl(u_1-\sum_{k=1}^{n-1}v_{0y_k}\frac{\partial\Phi_k}{\partial\xi}\Bigr)=:v_1(\hat y).\qquad(1.7)$$

## Лемма о производных на $\Sigma$

**Лемма 1.1.** Если $b^{nn}\ne0$ на $\Sigma$, то по данным (1.5)–(1.7) однозначно вычисляются значения всех производных решения $v$ на $\Sigma$.

*Доказательство.* Из $v|_{\Sigma}=v_0$ находим все производные, не содержащие дифференцирования по $y_n$; из $v_{y_n}|_\Sigma=v_1$ — все производные с однократным дифференцированием по $y_n$. Так как $b^{nn}\ne0$, из уравнения
$$v_{y_ny_n}=(b^{nn})^{-1}\Bigl(g-\sum_{k,l<n}b^{kl}v_{y_ky_l}-2\sum_{k<n}b^{kn}v_{y_ky_n}-\sum_kb^kv_{y_k}-bv\Bigr)\qquad(1.8)$$
находим на $\Sigma$ все производные с двукратным дифференцированием по $y_n$. Индукция: если найдены все производные с не более чем $k$-кратным дифференцированием по $y_n$, то, дифференцируя (1.8) $(k-1)$ раз по $y_n$ (и сколько угодно раз по $\hat y$), выражаем производные с $(k+1)$-кратным дифференцированием через уже найденные. $\square$

**Характеристический случай.** Если в точке $y\in\Sigma$ $b^{nn}=0$, то уравнение в этой точке не содержит $v_{y_ny_n}$:
$$\sum_{k,l<n}b^{kl}v_{y_ky_l}+2\sum_{k<n}b^{kn}v_{y_ky_n}+\sum_kb^kv_{y_k}+bv=g,\qquad(1.9)$$
а все входящие сюда производные уже выражены через $v_0,v_1$. Значит, (1.9) — **ограничение на данные**: они не могут быть произвольными. По (1.5) $b^{nn}=0$ ровно тогда, когда $(A\nabla F,\nabla F)=0$, — это и есть определение характеристической точки.

## Пример: данные на характеристике

Уравнение $u_{x_1x_1}-u_{x_2x_2}=0$. Здесь $A=\mathrm{diag}(1,-1)$, уравнение характеристик $F_{x_1}^2-F_{x_2}^2=0$, характеристики — прямые $x_1-x_2=C_1$, $x_1+x_2=C_2$. Ставим данные на характеристике $x_1=x_2$:
$$u_{x_1x_1}-u_{x_2x_2}=0,\qquad u|_{x_1=x_2}=u_0(x_2),\qquad u_{x_1}|_{x_1=x_2}=u_1(x_2).$$
Замена $y_1=x_1$, $y_2=x_1-x_2$, $v(y)=u(x)$: $u_{x_1}=v_{y_1}+v_{y_2}$, $u_{x_2}=-v_{y_2}$, $u_{x_1x_1}=v_{y_1y_1}+2v_{y_1y_2}+v_{y_2y_2}$, $u_{x_2x_2}=v_{y_2y_2}$, поэтому
$$v_{y_1y_1}+2v_{y_1y_2}=0,\qquad v|_{y_2=0}=u_0(y_1),\qquad v_{y_2}|_{y_2=0}=u_1(y_1)-u_0'(y_1).$$
При $y_2=0$ из уравнения: $u_0''+2(u_1'-u_0'')=0$, т.е. $2u_1'-u_0''=0$, или
$$2u_1-u_0'=C=\mathrm{const}.$$
- Если это условие нарушено, задача **не имеет решений** ни при какой гладкости данных.
- Если выполнено — решений **бесконечно много**:
$$u(x_1,x_2)=h(x_1-x_2)+u_0\Bigl(\frac{x_1+x_2}2\Bigr)-h(0),$$
где $h\in C^2(\mathbb R)$ — любая функция с $h'(0)=\frac C2$.

## Замечание: характеристики — линии разрыва вторых производных

Пусть кривая $\gamma=\{y=\phi(x)\}$ делит плоскость на $\Omega^\pm$, $u\in C^1(\mathbb R^2)$, $u\in C^2(\overline{\Omega^\pm})$, но $u\notin C^2(\mathbb R^2)$, и $u$ решает $Au_{xx}+Bu_{xy}+Cu_{yy}+\dots=f$ в $\Omega^\pm$ (коэффициенты непрерывны). Обозначим скачок $[g]=g^+-g^-$ на $\gamma$. Так как $[u]=[u_x]=[u_y]=0$, дифференцируя вдоль $\gamma$:
$$\tfrac{d}{dx}[u_x]=[u_{xx}]+[u_{xy}]\phi'=0,\qquad \tfrac d{dx}[u_y]=[u_{xy}]+[u_{yy}]\phi'=0 .$$
Если $[u_{yy}]=\lambda\ne0$, то $[u_{xy}]=-\lambda\phi'$, $[u_{xx}]=\lambda\phi'^2$. Вычитая уравнения по разные стороны: $A[u_{xx}]+B[u_{xy}]+C[u_{yy}]=0$, т.е. $A\phi'^2-B\phi'+C=0$ — **$\gamma$ — характеристика**.
