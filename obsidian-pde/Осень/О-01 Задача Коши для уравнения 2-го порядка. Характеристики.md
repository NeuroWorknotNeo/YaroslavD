# О-01. Задача Коши для уравнения 2-го порядка. Характеристики

> [!question] Формулировка билета
> Сформулировать задачу Коши для линейного уравнения с частными производными второго порядка. Переход к задаче с «начальными данными» на плоскости $y_n=0$. Понятие характеристики. Разобрать пример задачи Коши с данными на характеристике.

**Где в конспекте:** ч. 1, лекция 1 (с. 6–11), пример — лекция 2 (с. 14).

## Что рассказывать
- Оператор $Lu=\sum a_{ij}(x)u_{x_ix_j}+\sum b_iu_{x_i}+cu$, данные $u|_S=u_0$, $\partial_\nu u|_S=u_1$ на поверхности $S$ класса $C^2$.
- Локальная замена переменных выпрямляет $S$ в кусок плоскости $\{y_n=0\}$; уравнение сохраняет вид, меняются коэффициенты.
- Из данных находятся все производные на $S$, кроме $u_{y_ny_n}$; её можно выразить из уравнения, только если коэффициент при ней $\ne0$.
- Характеристика: $\sum a_{ij}\nu_i\nu_j=0$ на $S$ — тогда старшую производную выразить нельзя, данные связаны условием совместности.
- Пример: данные на характеристике — задача либо неразрешима, либо имеет бесконечно много решений.
