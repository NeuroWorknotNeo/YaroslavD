# О-18. Обобщённая производная по Соболеву

> [!question] Формулировка билета
> Обобщенная производная в смысле Соболева. Единственность обобщенной производной и другие свойства (примеры).

**Где в конспекте:** ч. 1, лекция 6 (с. 44–48).

## Кратко (план ответа)
- Мотивировка: для $f\in C^1(\Omega)$, $g\in C^1_0(\Omega)$ из формулы Стокса $\int_\Omega f_{x_j}g\,dx=-\int_\Omega fg_{x_j}\,dx$.
- Определение: $v=D^\alpha u$, если $\int uD^\alpha\varphi\,dx=(-1)^{|\alpha|}\int v\varphi\,dx$ для всех $\varphi\in C_0^\infty(\Omega)$.
- Единственность: из $\int(v_1-v_2)\varphi=0$ для всех $\varphi$ следует $v_1=v_2$ п.в. (основная лемма вариационного исчисления).
- Примеры: $|x|$ на $(-1,1)$ имеет обобщённую производную $\mathrm{sign}\,x$; $\mathrm{sign}\,x$ — нет.

---

## Мотивировка
Пусть $f\in C^1(\Omega)$, $g\in C_0^1(\Omega)$. По [[Формула Стокса|формуле Стокса]] (поле $(0,\dots,fg,\dots,0)$)
$$\int_\Omega\frac{\partial}{\partial x_j}(fg)\,dx=\int_{\partial\Omega}fg\,\nu_jds=0\quad\Longrightarrow\quad\int_\Omega f_{x_j}g\,dx=-\int_\Omega fg_{x_j}dx.\qquad(6.1)$$
Аналогично, для $f\in C^\infty(\Omega)$, $g\in C_0^\infty(\Omega)$ (повторяя $|\alpha|$ раз)
$$\int_\Omega f\,D^\alpha g\,dx=(-1)^{|\alpha|}\int_\Omega g\,D^\alpha f\,dx.\qquad(6.2)$$
Правая часть (6.2) имеет смысл и для негладких $f$, если есть подходящая функция на месте $D^\alpha f$ — это и берётся за определение.

## Определение
**Определение 6.16.** Пусть $\alpha=(\alpha_1,\dots,\alpha_n)$ — мультииндекс. Функция $w_\alpha\in L_{2,loc}(\Omega)$ называется **обобщённой производной** вида $D^\alpha u$ функции $u\in L_{2,loc}(\Omega)$ в смысле Соболева, если для всех $\phi\in C_0^\infty(\Omega)$
$$\int_\Omega w_\alpha\phi\,dx=(-1)^{|\alpha|}\int_\Omega u\,D^\alpha\phi\,dx .\qquad(6.3)$$
($\Omega$ — любая область, в том числе неограниченная.) Обозначение сохраняется: $w_\alpha=D^\alpha u$.

## Единственность
**Теорема 6.11.** Функция $u\in L_{2,loc}(\Omega)$ не может иметь двух разных обобщённых производных вида $D^\alpha u$.

*Доказательство.* Пусть $w_\alpha$, $\tilde w_\alpha$ — две обобщённые производные. Вычитая тождества (6.3),
$$\int_\Omega(w_\alpha-\tilde w_\alpha)\phi\,dx=0\qquad\forall\phi\in C_0^\infty(\Omega).\qquad(6.4)$$
Пусть $\Omega_1$ — ограниченная область, $\overline{\Omega_1}\subset\Omega$. Тогда (6.4) верно для всех $\phi\in C_0^\infty(\Omega_1)$, а $g=w_\alpha-\tilde w_\alpha\in L_2(\Omega_1)$. Так как $C_0^\infty(\Omega_1)$ плотно в $L_2(\Omega_1)$, найдутся $\phi_k\in C_0^\infty(\Omega_1)$, $\|\phi_k-g\|_{L_2(\Omega_1)}\to0$. Переходя к пределу в $\int_{\Omega_1}g\phi_k=0$ (неравенство Коши–Буняковского), получаем $\int_{\Omega_1}g^2dx=0$, т.е. $g=0$ п.в. в $\Omega_1$. По произвольности $\Omega_1$ — п.в. в $\Omega$. $\square$

## Свойства
1. **Согласованность с классической производной.** Если $u\in C^{|\alpha|}(\Omega)$, то классическая производная является обобщённой (формула (6.2)), и по единственности они совпадают.
2. **Линейность:** $D^\alpha(c_1u+c_2v)=c_1D^\alpha u+c_2D^\alpha v$ (линейность (6.3)).
3. **Локальность:** если $u$ имеет $D^\alpha u$ в $\Omega$, то и в любой подобласти $\Omega'\subset\Omega$, причём это сужение $D^\alpha u$ (пробные функции из $C_0^\infty(\Omega')$ продолжаются нулём).
4. **Замкнутость:** если $u_k\to u$ и $D^\alpha u_k\to w$ в $L_2(\Omega)$ (или в $L_{2,loc}$), то $w=D^\alpha u$ (предельный переход в (6.3)). Это используется при доказательстве полноты $H^1$.
5. Обобщённая производная не определяется поточечно: функции, совпадающие п.в., имеют одинаковые обобщённые производные.

## Примеры
**1.** $u(x)=x$ при $0\le x\le1$, $u=1$ при $1\le x\le2$. Для $\phi\in C_0^\infty(0,2)$
$$\int_0^2u\phi'dx=\int_0^1x\phi'dx+\int_1^2\phi'dx=\bigl(\phi(1)-\int_0^1\phi\bigr)+(0-\phi(1))=-\int_0^2\chi_{[0,1]}\phi\,dx,$$
поэтому $u'=\chi_{[0,1]}$: $u'=1$ на $[0,1]$, $u'=0$ на $(1,2]$ (излом — не помеха).

**2.** $u(x)=x$ при $0\le x\le1$, $u=2$ при $1<x\le2$ (скачок). Для $\phi\in C_0^\infty(0,2)$
$$\int_0^2u\phi'dx=-\int_0^1\phi\,dx-\phi(1).$$
Если бы обобщённая производная $u'$ существовала, то $\int_0^2u'\phi\,dx=\int_0^1\phi\,dx+\phi(1)$ для всех $\phi$ (6.9). Возьмём $\phi_k\in C_0^\infty(0,2)$, $0\le\phi_k\le1$, $\phi_k(1)=1$, $\operatorname{supp}\phi_k\subset[1-\frac1k,1+\frac1k]$. Тогда левая часть $\to0$ (абсолютная непрерывность интеграла), а правая $\to1$ — противоречие. **Обобщённой производной нет**: скачок «не прощается».

**3.** $|x|^\varepsilon$ в единичном шаре — см. [[О-19 Пространство Соболева H1|О-19]].
