# О-18. Обобщённая производная по Соболеву

> [!question] Формулировка билета
> Обобщенная производная в смысле Соболева. Единственность обобщенной производной и другие свойства (примеры).

**Где в конспекте:** ч. 1, лекция 6 (с. 44–48).

## Что рассказывать
- Мотивировка: для $f\in C^1(\Omega)$, $g\in C^1_0(\Omega)$ из формулы Стокса $\int_\Omega f_{x_j}g\,dx=-\int_\Omega fg_{x_j}\,dx$.
- Определение: $v=D^\alpha u$, если $\int uD^\alpha\varphi\,dx=(-1)^{|\alpha|}\int v\varphi\,dx$ для всех $\varphi\in C_0^\infty(\Omega)$.
- Единственность: из $\int(v_1-v_2)\varphi=0$ для всех $\varphi$ следует $v_1=v_2$ п.в. (основная лемма вариационного исчисления).
- Примеры: $|x|$ на $(-1,1)$ имеет обобщённую производную $\mathrm{sign}\,x$; $\mathrm{sign}\,x$ — нет.
