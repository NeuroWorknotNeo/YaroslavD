# О-21. Неравенство Фридрихса

> [!question] Формулировка билета
> Неравенство Фридрихса.

**Где в конспекте:** ч. 1, лекция 7 (с. 50–51).

## Кратко (план ответа)
- $u\in H^1_0(\Omega)$, $\Omega$ ограничена $\Rightarrow$ $\|u\|_{L_2(\Omega)}\le C(\Omega)\|\nabla u\|_{L_2(\Omega)}$.
- Для $u\in C_0^\infty$: $\overline\Omega\subset\Pi_a$, продолжаем нулём, Ньютон–Лейбниц по $x_1$, Коши–Буняковский, интегрирование по $\Pi_a$: $\int u^2\le2a_1^2\int|\nabla u|^2$.
- Для $u\in H^1_0$ — предельный переход.
- Следствия: $(u,v)=\int\nabla u\nabla v$ — эквивалентное скалярное произведение на $H^1_0$; $1\in H^1\setminus H^1_0$.

---

## Формулировка
**Неравенство Фридрихса.** Пусть $\Omega$ — ограниченная область, $u\in H^1_0(\Omega)$. Тогда
$$\|u\|_{L_2(\Omega)}\le C(\Omega)\,\|\nabla u\|_{L_2(\Omega)} .\qquad(7.2)$$

## Доказательство
**Шаг 1: $u\in C_0^\infty(\Omega)$.** Пусть $\overline\Omega\subset\Pi_a=\{x:\ -a_j<x_j<a_j\}$, $a_1=\min_ja_j$ (переобозначив оси, считаем минимальную полуширину по $x_1$). Продолжим $u$ нулём на $\Pi_a\setminus\overline\Omega$ — получим функцию из $C_0^\infty(\Pi_a)$. По формуле Ньютона–Лейбница ($u(-a_1,\hat x)=0$)
$$u(x)=\int_{-a_1}^{x_1}u_{y_1}(y_1,\hat x)\,dy_1,\qquad\hat x=(x_2,\dots,x_n).$$
Возводим в квадрат и применяем неравенство Коши–Буняковского:
$$u^2(x)\le(x_1+a_1)\int_{-a_1}^{x_1}u_{y_1}^2dy_1\le(x_1+a_1)\int_{-a_1}^{a_1}u_{x_1}^2(y_1,\hat x)dy_1 .$$
Интегрируем по $x_1\in(-a_1,a_1)$ (правый интеграл от $x_1$ не зависит, $\int_{-a_1}^{a_1}(x_1+a_1)dx_1=2a_1^2$) и затем по $\hat x$:
$$\int_\Omega u^2dx=\int_{\Pi_a}u^2dx\le2a_1^2\int_{\Pi_a}u_{x_1}^2dx\le2a_1^2\int_\Omega|\nabla u|^2dx .\qquad(7.3)$$
**Шаг 2: $u\in H^1_0(\Omega)$.** Есть $u_m\in C_0^\infty(\Omega)$, $\|u_m-u\|_{H^1}\to0$. Для $u_m$ верно (7.3); так как $\|u_m\|_{L_2}\to\|u\|_{L_2}$ и $\|\nabla u_m\|_{L_2}\to\|\nabla u\|_{L_2}$, переходим к пределу. $\square$

Постоянная: $C(\Omega)=\sqrt2\,a_1$. Достаточно, чтобы $\Omega$ была ограничена **в одном направлении** (лежала в полосе $|x_1|<a_1$).

## Следствия
1. **$H^1_0(\Omega)\ne H^1(\Omega)$.** $u\equiv1\in H^1(\Omega)$, $\nabla u=0$, но $\|u\|_{L_2}=|\Omega|^{1/2}>0$ — неравенство (7.2) нарушено, значит, $1\notin H^1_0$.
2. **Эквивалентная норма.** Из (7.2) $\|\nabla u\|^2_{L_2}\le\|u\|^2_{H^1}\le(1+C^2)\|\nabla u\|^2_{L_2}$, поэтому
$$(u,v)_{H^1_0(\Omega)}=\int_\Omega\nabla u\cdot\nabla v\,dx,\qquad\|u\|_{H^1_0}=\|\nabla u\|_{L_2}\qquad(7.4),(7.5)$$
— скалярное произведение на $H^1_0$, эквивалентное исходному. (Без Фридрихса из $\int|\nabla u|^2=0$ следовало бы лишь $u=\mathrm{const}$.)
3. Применения: ограниченность функционалов в теореме Рисса (задача Дирихле), оценка снизу в вариационном методе, $\lambda_1<0$ в задаче на собственные значения. См. [[Неравенство Фридрихса]].
