# О-31. Существование обобщённого решения (метод Фурье)

> [!question] Формулировка билета
> Теорема существования обобщенного решения первой начально-краевой задачи для волнового уравнения (Метод Фурье).

**Где в конспекте:** ч. 1, лекции 10–11 (с. 77–83).

## Кратко (план ответа)
- Ищем $u=\sum_kT_k(t)w_k(x)$ по собственным функциям задачи Дирихле.
- Для $T_k$ — ОДУ $T_k''+\lambda_kT_k=f_k$ с начальными данными — коэффициенты Фурье $\varphi$, $\psi$.
- Сходимость ряда в $H^1(Q_T)$: оценки через $\|\varphi\|_{H^1_0}$, $\|\psi\|_{L_2}$, $\|f\|_{L_2}$ и ортогональность.
- Предел удовлетворяет интегральному тождеству — обобщённое решение.

---

## Формулировка
**Теорема 10.25.** Пусть $u_0\in H^1_0(\Omega)$, $u_1\in L_2(\Omega)$, $f\in L_2(Q_T)$. Тогда задача
$$u_{tt}=\Delta u+f\ \text{в }Q_T,\qquad u|_{\Gamma_T}=0,\qquad u|_{t=0}=u_0,\qquad u_t|_{t=0}=u_1\qquad(10.1)$$
имеет обобщённое решение (определение — в [[О-29 Начально-краевые задачи для волнового уравнения. Единственность|О-29]]), и
$$\|u\|^2_{H^1(Q_T)}\le K(T)\bigl(\|u_0\|^2_{H^1_0(\Omega)}+\|u_1\|^2_{L_2(\Omega)}+\|f\|^2_{L_2(Q_T)}\bigr).$$

## Доказательство
**0. Базис.** Пусть $\{w_k\}$ — собственные функции задачи Дирихле для оператора Лапласа ($\Delta w_k=\lambda_kw_k$, $\lambda_k<0$), ортогональный базис в $H^1_0(\Omega)$ и ортонормированный в $L_2(\Omega)$, $\|w_k\|^2_{H^1_0}=-\lambda_k=|\lambda_k|$ ([[О-30 Собственные функции и собственные значения задачи Дирихле|О-30]]). Разложим данные:
$$u_0=\sum_ku_{0,k}w_k,\ u_{0,k}=(u_0,w_k)_{L_2},\ \|u_0\|^2_{H^1_0}=\sum_ku_{0,k}^2|\lambda_k|;\qquad u_1=\sum_ku_{1,k}w_k,\ \|u_1\|^2_{L_2}=\sum u_{1,k}^2;\qquad(10.12),(10.13)$$
$$f(x,t)=\sum_kf_k(t)w_k(x),\quad f_k(t)=(f(\cdot,t),w_k)_{L_2(\Omega)}\in L_2(0,T),\quad\sum_k\int_0^Tf_k^2dt=\int_{Q_T}f^2\qquad(10.14),(10.15)$$
($\int_0^Tf_k^2\le\int_0^T\int_\Omega f^2\int_\Omega w_k^2=\|f\|^2_{L_2(Q_T)}$; равенство (10.15) — Парсеваль для п.в. $t$ и теорема Леви).

**1. Одна гармоника.** Рассмотрим задачу
$$u_{ktt}-\Delta u_k=f_k(t)w_k(x),\qquad u_k|_{\Gamma_T}=0,\qquad u_k|_{t=0}=u_{0,k}w_k,\qquad u_{kt}|_{t=0}=u_{1,k}w_k .\qquad(10.16)$$
Её обобщённое решение — $u_k=V_k(t)w_k(x)$, где $V_k$ решает задачу Коши для ОДУ
$$V_k''-\lambda_kV_k=f_k(t),\qquad V_k(0)=u_{0,k},\qquad V_k'(0)=u_{1,k},\qquad(10.17)$$
т.е. (формула вариации постоянных)
$$V_k(t)=u_{0,k}\cos\sqrt{|\lambda_k|}t+\frac{u_{1,k}}{\sqrt{|\lambda_k|}}\sin\sqrt{|\lambda_k|}t+\frac1{\sqrt{|\lambda_k|}}\int_0^tf_k(\tau)\sin\bigl(\sqrt{|\lambda_k|}(t-\tau)\bigr)d\tau,$$
$V_k\in H^1(0,T)$, $V_k''\in L_2(0,T)$. Проверка тождества (10.18): для $v\in H^1(Q_T)$, $v|_{\Gamma_T}=0$, $v|_{t=T}=0$, используя $\int_\Omega\nabla w_k\nabla\psi=-\lambda_k\int_\Omega w_k\psi$ ($\psi\in H^1_0$) и интегрирование по частям по $t$ (с $v(\cdot,T)=0$):
$$M_k=\int_{Q_T}\bigl(-V_k'\partial_tv\,w_k+V_k(\nabla w_k,\nabla v)\bigr)=\int_{Q_T}V_k''vw_k-\lambda_k\int_{Q_T}V_kw_kv+\int_\Omega u_{1,k}w_kv(x,0)dx$$
$$=\int_{Q_T}(V_k''-\lambda_kV_k)w_kv+\int_\Omega u_{1,k}w_kv(x,0)=\int_{Q_T}f_kw_kv+\int_\Omega u_{1,k}w_kv(x,0)dx .$$
По линейности $S_N=\sum_{k=1}^NV_k(t)w_k(x)$ — обобщённое решение задачи с данными, обрезанными до $N$ гармоник (10.20).

**2. Оценки коэффициентов.** Из формулы для $V_k$ и неравенств $(a+b+c)^2\le3(a^2+b^2+c^2)$, $\bigl(\int_0^t|f_k|\bigr)^2\le T\int_0^Tf_k^2$:
$$V_k^2(t)\le3\Bigl(u_{0,k}^2+\frac{u_{1,k}^2}{|\lambda_k|}+\frac T{|\lambda_k|}\int_0^Tf_k^2dt\Bigr),\qquad(10.22)$$
$$(V_k'(t))^2\le3\Bigl(|\lambda_k|u_{0,k}^2+u_{1,k}^2+T\int_0^Tf_k^2dt\Bigr)$$
(в $V_k'$ производная интеграла: $\int_0^tf_k(\tau)\cos(\sqrt{|\lambda_k|}(t-\tau))d\tau$).

**3. Фундаментальность.** По ортогональности $w_k$ в $H^1_0$ и в $L_2$, для п.в. $t$:
$$\|S_N-S_M\|^2_{H^1_0(\Omega_t)}=\sum_{k=M+1}^NV_k^2(t)|\lambda_k|\le3\sum_{k=M+1}^N\Bigl(|\lambda_k|u_{0,k}^2+u_{1,k}^2+T\int_0^Tf_k^2\Bigr),\qquad(10.21)$$
$$\|\partial_tS_N-\partial_tS_M\|^2_{L_2(\Omega_t)}=\sum_{k=M+1}^N(V_k')^2\le3\sum_{k=M+1}^N\Bigl(|\lambda_k|u_{0,k}^2+u_{1,k}^2+T\int_0^Tf_k^2\Bigr).\qquad(11.1)$$
Правые части — хвосты сходящихся рядов (10.13), (10.15), они $\to0$ при $M,N\to\infty$ равномерно по $t$. Кроме того, $\|S_N-S_M\|_{L_2(\Omega_t)}\le C\|S_N-S_M\|_{H^1_0(\Omega_t)}$ (Фридрихс). Интегрируя по $t\in(0,T)$, получаем, что $\{S_N\}$ фундаментальна в $H^1(Q_T)$. По полноте $S_N\to u$ в $H^1(Q_T)$, $u=\sum_kV_k(t)w_k(x)$.

**4. Предельный переход.** В тождестве для $S_N$ обрезанные данные сходятся: $\sum_{k\le N}u_{1,k}w_k\to u_1$ в $L_2(\Omega)$, $\sum_{k\le N}f_kw_k\to f$ в $L_2(Q_T)$, а $S_N\to u$ в $H^1(Q_T)$. Все члены тождества непрерывны относительно этих сходимостей (Коши–Буняковский), поэтому $u$ удовлетворяет (10.4). Начальное условие: $S_N(\cdot,0)=\sum_{k\le N}u_{0,k}w_k\to u_0$ в $H^1_0(\Omega)$, и по непрерывности следа $u|_{t=0}=u_0$; $u|_{\Gamma_T}=0$, так как $S_N(\cdot,t)\in H^1_0(\Omega)$.

**5. Оценка.** Из (10.22) $\|S_N\|^2_{H^1_0(\Omega_t)}\le K_0(T)\sum_k\bigl(|\lambda_k|u_{0,k}^2+u_{1,k}^2+\int_0^Tf_k^2\bigr)$, аналогично для $\|\partial_tS_N\|^2_{L_2(\Omega_t)}$ (11.2), (11.3). Интегрируя по $t$ и переходя к пределу, получаем оценку теоремы. $\square$

## Пример: классическое решение методом Фурье
Струна длины $l$ с закреплёнными концами:
$$u_{tt}=u_{xx},\ x\in(0,l);\qquad u(x,0)=u_0(x),\ u_t(x,0)=u_1(x);\qquad u(0,t)=u(l,t)=0 .$$
Если $u_0\in C^3[0,l]$, $u_0(0)=u_0(l)=u_0''(0)=u_0''(l)=0$, $u_1\in C^2[0,l]$, $u_1(0)=u_1(l)=0$, то решение, построенное методом Фурье,
$$u(x,t)=\sum_{k=1}^\infty\Bigl(\phi_k\cos\frac{\pi kt}l+\frac{\psi_kl}{\pi k}\sin\frac{\pi kt}l\Bigr)\sin\frac{\pi kx}l$$
($\phi_k,\psi_k$ — коэффициенты Фурье $u_0,u_1$ по $\sin\frac{\pi kx}l$) **классическое**: $u\in C^2([0,l]\times[0,T])$.

*Доказательство.* Интегрируя по частям три раза (внеинтегральные члены исчезают благодаря условиям на концах), $\phi_k=\pm\bigl(\frac l{\pi k}\bigr)^3d_k$, где $d_k$ — коэффициенты Фурье $u_0'''$ по системе $\{1,\cos\frac{\pi kx}l\}$; дважды — $\psi_k=-\bigl(\frac l{\pi k}\bigr)^2C_k$, $C_k$ — коэффициенты Фурье $u_1''$ по $\{\sin\frac{\pi kx}l\}$. По неравенству Бесселя $\sum(C_k^2+d_k^2)<\infty$, и по Коши–Буняковскому
$$\sum_k\frac1k(|d_k|+|C_k|)\le\Bigl(\sum\frac1{k^2}\Bigr)^{1/2}\Bigl(2\sum(d_k^2+C_k^2)\Bigr)^{1/2}<\infty,$$
что равносильно $\sum_k(k^2|\phi_k|+k|\psi_k|)<\infty$. Значит, ряды из вторых производных членов ряда сходятся равномерно (мажоранта $\frac{\pi^2}{l^2}\sum(k^2|\phi_k|+\frac l\pi k|\psi_k|)$), ряд можно дважды почленно дифференцировать по $x$ и $t$, и сумма — классическое решение. $\square$
