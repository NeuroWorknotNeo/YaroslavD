# О-09. Энергетическое неравенство. Единственность для волнового уравнения

> [!question] Формулировка билета
> Энергетическое неравенство для решения волнового уравнения. Постановка задачи Коши. Единственность классического решения задачи Коши.

**Где в конспекте:** ч. 1, лекция 3 (с. 24–28), следствия — лекция 4 (с. 29).

## Что рассказывать
- Характеристический конус $K_{x_0,T}=\{|x-x_0|<T-t,\ 0\le t\le T\}$, сечения $\Omega_t$.
- $E(t)=\int_{\Omega_t}(u_t^2+|\nabla_xu|^2)\,dx$ не возрастает: $E(t_2)\le E(t_1)$.
- Доказательство: умножить уравнение на $u_t$, проинтегрировать по усечённому конусу, применить формулу Стокса в $\mathbb R^{n+1}$; интеграл по боковой поверхности $\ge0$, т.к. $u_t^2+|\nabla u|^2-2u_t(\nabla u,\vec n)\ge(|u_t|-|\nabla u|)^2$.
- Следствие: разность двух решений с одинаковыми данными имеет $E\equiv0$ $\Rightarrow$ решения совпадают.

## Методы доказательства
- [[Формула Стокса]] — интеграл по усечённому конусу в $\mathbb R^{n+1}$
- [[Многомерное интегрирование по частям]] — перенос производных с $u_t\Delta u$
- [[Энергетический метод]] — сама идея доказательства
