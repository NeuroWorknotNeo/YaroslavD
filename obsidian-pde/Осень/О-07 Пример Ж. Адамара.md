# О-07. Пример Ж. Адамара

> [!question] Формулировка билета
> Пример Ж. Адамара.

**Где в конспекте:** ч. 1, лекция 3 (с. 20).

## Кратко (план ответа)
- Задача Коши для уравнения Лапласа $u_{xx}+u_{yy}=0$, $u(x,0)=\dfrac{\cos nx}{n}$, $u_y(x,0)=0$.
- Решение $u_n=\dfrac{\mathrm{ch}(ny)\cos nx}{n}$: данные $\to0$ равномерно, а в любой полосе $|y|\le\delta$ $\sup|u_n|=\frac{\mathrm{ch}\,n\delta}n\to\infty$.
- Вывод: аналитическое решение существует (Коши–Ковалевская), но непрерывной зависимости от данных нет — задача некорректна.

---

## Мотивировка
Многие задачи физики приводят к задаче Коши для аналитических уравнений, но с **неаналитическими** данными. Естественная идея: приблизить данные многочленами (теорема Вейерштрасса), решить задачи Коши с полиномиальными данными по теореме Коши–Ковалевской и надеяться, что решения близки к искомому. Ж. Адамар показал, что так бывает не всегда.

## Пример
Задача Коши для уравнения Лапласа на плоскости:
$$u_{xx}+u_{yy}=0,\qquad u|_{y=0}=\frac{\cos nx}n,\qquad u_y|_{y=0}=0,\qquad x\in\mathbb R .$$
Прямая $y=0$ не характеристика (у уравнения Лапласа характеристик нет: $(A\nabla F,\nabla F)=|\nabla F|^2>0$), поэтому по теореме Коши–Ковалевской аналитическое решение существует и единственно. Это
$$u_n(x,y)=\frac{\mathrm{ch}(ny)\cos(nx)}n$$
(проверка: $u_{xx}=-n\,\mathrm{ch}(ny)\cos nx$, $u_{yy}=n\,\mathrm{ch}(ny)\cos nx$; $u_n(x,0)=\frac{\cos nx}n$, $\partial_yu_n|_{y=0}=\mathrm{sh}(0)\cos nx=0$).

В полосе $\{|y|<\delta\}$:
$$\sup_{\mathbb R}|u_n(x,0)|=\frac1n\to0,\qquad\sup_{\mathbb R\times[-\delta,\delta]}|u_n(x,y)|=\frac{\mathrm{ch}(n\delta)}n\to\infty\quad(n\to\infty).$$
Данные сколь угодно малы, а решения неограниченно велики: **непрерывной зависимости решения от данных нет**.

## Корректность по Адамару
Пусть задача записана как $\Lambda u=\Phi$, $\Lambda:B_1\to B_2$ — оператор задачи, $B_1,B_2$ — банаховы пространства (решений и данных).

**Определение 3.9.** Задача $\Lambda u=\Phi$ **корректна** в паре $B_1,B_2$, если
1. для любого $\Phi\in B_2$ существует $u\in B_1$ с $\Lambda u=\Phi$ (существование);
2. из $\Lambda u_1=\Lambda u_2=\Phi$ следует $u_1=u_2$ (единственность);
3. малому изменению $\Phi$ в $B_2$ соответствует сколь угодно малое изменение решения в $B_1$ (устойчивость, непрерывная зависимость).

Для $B_1=\{u\in C(\overline\Omega):|u|\le M\}$, $B_2=\{\phi\in C(\mathbb R):|\phi|\le C\}$ пример Адамара показывает, что задача Коши для уравнения Лапласа **некорректна** (нарушен пункт 3). Для уравнения Лапласа естественны краевые задачи (Дирихле, Неймана), а не задача Коши.
