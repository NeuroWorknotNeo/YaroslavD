# О-07. Пример Ж. Адамара

> [!question] Формулировка билета
> Пример Ж. Адамара.

**Где в конспекте:** ч. 1, лекция 3 (с. 20).

## Что рассказывать
- Задача Коши для уравнения Лапласа $u_{xx}+u_{yy}=0$, $u(x,0)=0$, $u_y(x,0)=\dfrac{\sin nx}{n}$.
- Решение $u=\dfrac{\sin nx\,\mathrm{sh}\,ny}{n^2}$: данные $\to0$ равномерно, а решение при любом $y>0$ неограниченно растёт.
- Вывод: аналитическое решение существует (Коши–Ковалевская), но непрерывной зависимости от данных нет — задача некорректна.
