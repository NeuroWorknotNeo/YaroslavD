# О-15. Нелинейное одномерное волновое уравнение. Сжимающие отображения

> [!question] Формулировка билета
> Теорема о разрешимости задачи Коши для одномерного нелинейного волнового уравнения. Применение принципа сжимающего отображения.

**Где в конспекте:** в конспекте явно не выделено — восстанавливается по формуле Даламбера (ч. 1, лекции 5–6).

## Что рассказывать
- Уравнение $u_{tt}-u_{xx}=f(x,t,u)$ с липшицевой по $u$ правой частью.
- По формуле Даламбера и принципу Дюамеля задача равносильна интегральному уравнению $u=u^0+\frac12\iint_{\Delta(x,t)}f(\xi,s,u)\,d\xi\,ds$ (интеграл по характеристическому треугольнику).
- Оператор справа — сжатие в $C$ на малом промежутке по $t$ (или в норме с весом $e^{-\lambda t}$).
- Неподвижная точка — решение; единственность следует из того же сжатия.
