# О-15. Нелинейное одномерное волновое уравнение. Сжимающие отображения

> [!question] Формулировка билета
> Теорема о разрешимости задачи Коши для одномерного нелинейного волнового уравнения. Применение принципа сжимающего отображения.

**Где в конспекте:** в конспекте явно не выделено — восстанавливается по формуле Даламбера (ч. 1, лекции 5–6).

## Кратко (план ответа)
- Уравнение $u_{tt}-u_{xx}=f(x,t,u)$ с липшицевой по $u$ правой частью.
- По формуле Даламбера и принципу Дюамеля задача равносильна интегральному уравнению $u=u^0+\frac12\iint_{\Delta(x,t)}f(\xi,s,u)\,d\xi\,ds$ (интеграл по характеристическому треугольнику).
- Оператор справа — сжатие в $C$ на малом промежутке по $t$ (или в норме с весом $e^{-\lambda t}$).
- Неподвижная точка — решение; единственность следует из того же сжатия.

---

> [!info] В конспекте этот вопрос не разобран. Ниже — стандартная теорема с полным доказательством.

## Постановка
$$u_{tt}-u_{xx}=f(x,t,u),\quad x\in\mathbb R,\ 0<t\le T;\qquad u|_{t=0}=u_0(x),\quad u_t|_{t=0}=u_1(x).\qquad(N)$$

**Предположения.** $u_0\in C^2(\mathbb R)$, $u_1\in C^1(\mathbb R)$ — ограниченные вместе с указанными производными; $f\in C^1(\mathbb R\times[0,T]\times\mathbb R)$,
$$|f(x,t,0)|\le K,\qquad|f(x,t,u)-f(x,t,v)|\le L|u-v|\quad(\text{например, }|f_u|\le L).$$

**Теорема.** При этих условиях задача (N) имеет единственное классическое решение $u\in C^2(\mathbb R\times[0,T])$, ограниченное в полосе.

## Шаг 1. Сведение к интегральному уравнению
Пусть $u$ — классическое решение. Тогда $F(x,t)=f(x,t,u(x,t))\in C^1$, и $u$ — классическое решение **линейной** задачи $u_{tt}-u_{xx}=F$ с теми же данными. По формуле Даламбера (теорема 5.9, единственность — теорема 4.4)
$$u(x,t)=u^0(x,t)+\frac12\int_0^t\int_{x-(t-\tau)}^{x+(t-\tau)}f(\xi,\tau,u(\xi,\tau))\,d\xi\,d\tau=:(\mathcal Au)(x,t),\qquad(I)$$
где $u^0=\frac{u_0(x+t)+u_0(x-t)}2+\frac12\int_{x-t}^{x+t}u_1$. Интеграл берётся по **характеристическому треугольнику** с вершиной $(x,t)$.

## Шаг 2. Сжатие
Пространство $X=C_b(\mathbb R\times[0,T])$ ограниченных непрерывных функций с нормой
$$\|u\|_\lambda=\sup_{x,t}e^{-\lambda t}|u(x,t)|,\qquad\lambda>0$$
(эквивалентна sup-норме, т.к. $e^{-\lambda T}\le e^{-\lambda t}\le1$; $X$ полно). $\mathcal A:X\to X$: подынтегральная функция ограничена ($|f(\cdot,\cdot,u)|\le K+L\|u\|_\infty$), площадь треугольника $\le t^2$, непрерывность — по непрерывности интеграла. Для $u,v\in X$:
$$|(\mathcal Au-\mathcal Av)(x,t)|\le\frac12\int_0^t2(t-\tau)\,L\sup_\xi|u-v|(\xi,\tau)\,d\tau\le L\|u-v\|_\lambda\int_0^t(t-\tau)e^{\lambda\tau}d\tau\le\frac{L}{\lambda^2}e^{\lambda t}\|u-v\|_\lambda$$
(так как $\int_0^t(t-\tau)e^{\lambda\tau}d\tau=\frac{e^{\lambda t}-1-\lambda t}{\lambda^2}\le\frac{e^{\lambda t}}{\lambda^2}$). Значит,
$$\|\mathcal Au-\mathcal Av\|_\lambda\le\frac L{\lambda^2}\|u-v\|_\lambda,$$
и при $\lambda^2>L$ отображение $\mathcal A$ — **сжатие**. По [[Принцип сжимающих отображений|принципу сжимающих отображений]] у (I) есть единственное решение $u\in X$, и оно — предел итераций $u^{k+1}=\mathcal Au^k$.

## Шаг 3. Гладкость
Пусть $u\in X$ решает (I) и $F(x,t)=f(x,t,u(x,t))$ (пока только непрерывна). Для $I(x,t)=\frac12\int_0^t\int_{x-t+\tau}^{x+t-\tau}F\,d\xi d\tau$:
$$I_x=\frac12\int_0^t\bigl[F(x+t-\tau,\tau)-F(x-t+\tau,\tau)\bigr]d\tau,\qquad I_t=\frac12\int_0^t\bigl[F(x+t-\tau,\tau)+F(x-t+\tau,\tau)\bigr]d\tau$$
(граничный член при $\tau=t$ равен нулю), — непрерывны. Значит, $u=u^0+I\in C^1$, тогда $F\in C^1$ (композиция $C^1$-функций), и по теореме 5.9 $I\in C^2$ решает $I_{tt}-I_{xx}=F$, $I|_{t=0}=I_t|_{t=0}=0$. Следовательно, $u\in C^2$ — классическое решение (N).

## Шаг 4. Единственность
Любое ограниченное классическое решение удовлетворяет (I) (шаг 1) и лежит в $X$, а решение (I) в $X$ единственно (шаг 2). $\square$

## Замечания
- Без глобальной липшицевости (например, $f=u^3$) получается только **локальная** разрешимость: берут малое $T$ и сжатие в шаре пространства $X$.
- Ключ — конечная скорость распространения: значение в $(x,t)$ зависит только от значений в треугольнике под ним, поэтому интегральный оператор имеет «вольтерровский» характер и вес $e^{-\lambda t}$ делает его сжатием.
