# О-33. Метод Ритца

> [!question] Формулировка билета
> Метод Ритца.

**Где в конспекте:** ч. 1, лекция 8 (с. 65–67).

## Кратко (план ответа)
- Берём конечномерные подпространства $V_N=\mathrm{span}(\varphi_1,\dots,\varphi_N)$, полная система в $H$.
- Минимизируем $E$ на $V_N$ — линейная система с матрицей Грама $((\varphi_i,\varphi_j)_H)$.
- Последовательность минимизаторов $u_N$ минимизирующая $\Rightarrow$ $u_N\to u$ в $H$.

---

## Идея
Минимум функционала $E(u)=\|u\|^2_H+2(f,u)_{L_2}$ (см. [[О-32 Вариационный метод. Минимум функционала|О-32]]) ищется приближённо на конечномерных подпространствах — задача сводится к линейной системе.

## Построение
Пусть $\{\psi_k\}$ — линейно независимая система функций, линейная оболочка которой всюду плотна в $H$. Например, для $H=H^1_0(\Omega)$ — собственные функции задачи Дирихле для оператора Лапласа; для $H=H^1(\Omega)$ — одночлены $x^\alpha=x_1^{\alpha_1}\cdots x_n^{\alpha_n}$.

Пусть $R_k=\langle\psi_1,\dots,\psi_k\rangle$ — $k$-мерное подпространство $H$ (замкнуто). По теореме 8.18 (применённой к $R_k$) существует единственный $v_k\in R_k$ с
$$E(v_k)=\inf_{u\in R_k}E(u).$$
Любой элемент $R_k$ — это $c_1\psi_1+\dots+c_k\psi_k$, поэтому нужно минимизировать функцию $k$ переменных
$$F(c_1,\dots,c_k)=E\Bigl(\sum c_j\psi_j\Bigr)=\sum_{i,j=1}^kc_ic_j(\psi_i,\psi_j)_H+2\sum_{j=1}^kc_j(f,\psi_j)_{L_2}.$$
Точка минимума удовлетворяет $\partial_{c_j}F=0$ (8.20), т.е. линейной системе
$$\sum_{i=1}^kc_i(\psi_i,\psi_j)_H+(f,\psi_j)_{L_2}=0,\qquad j=1,\dots,k .\qquad(8.21)$$
Её определитель — определитель Грама $\det\bigl((\psi_i,\psi_j)_H\bigr)\ne0$ (линейная независимость). Значит, (8.21) имеет единственное решение, и соответствующая $v_k\in R_k$ реализует минимум $E$ на $R_k$. Последовательность $\{v_k\}$ — **последовательность Ритца**.

## Сходимость
**Теорема 8.20.** Последовательность Ритца $\{v_k\}$ — минимизирующая для $E$ на $H$; она сходится в $H^1(\Omega)$ к функции $u$, реализующей минимум $E$ на $H$.

*Доказательство.* Так как $R_1\subset R_2\subset\dots\subset H$, то $E(v_1)\ge E(v_2)\ge\dots\ge d$ — монотонно убывающая последовательность. Пусть $u$ — точка минимума на $H$. По плотности оболочки для $\varepsilon>0$ есть $k(\varepsilon)$ и $u_\varepsilon=\sum_{j=1}^{k(\varepsilon)}c_j\psi_j\in R_{k(\varepsilon)}$ с $\|u_\varepsilon-u\|_H<\varepsilon$ (8.22). Раскрывая квадрат,
$$E(u_\varepsilon)=E(u)+\|u_\varepsilon-u\|^2_H+2(u_\varepsilon-u,u)_H+2(f,u_\varepsilon-u)\le d+\varepsilon^2+2\varepsilon\|u\|_H+2C\|f\|\varepsilon\le d+C_0\varepsilon\qquad(8.23)$$
(использованы Коши–Буняковский и эквивалентность норм). Так как минимум $E$ на $R_{k(\varepsilon)}$ достигается на $v_{k(\varepsilon)}$, а $E(v_s)$ убывает, для всех $s>k(\varepsilon)$
$$d\le E(v_s)\le E(v_{k(\varepsilon)})\le E(u_\varepsilon)\le d+C_0\varepsilon .$$
Значит, $E(v_s)\to d$, последовательность минимизирующая, и по теореме 8.18б $v_s\to u$ в $H^1$. $\square$

**Следствие.** Для $H=H^1_0(\Omega)$ последовательность Ритца, построенная по любой линейно независимой системе с плотной оболочкой, сходится в $H^1(\Omega)$ к обобщённому решению задачи Дирихле (теоремы 8.19, 8.20). Если взять собственные функции Лапласа, матрица Грама диагональна, и $v_k$ — частичная сумма ряда Фурье решения.
