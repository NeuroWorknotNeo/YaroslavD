# О-20. Пространство H1_0. Формула интегрирования по частям

> [!question] Формулировка билета
> Пространство $H^1_0(\Omega)$ и его свойства (гильбертово, сепарабельно). Формула интегрирования по частям.

**Где в конспекте:** ч. 1, лекция 6 (с. 47), лекция 7 (с. 50).

## Что рассказывать
- $H^1_0(\Omega)$ — замыкание $C_0^\infty(\Omega)$ в норме $H^1$; замкнутое подпространство гильбертова сепарабельного пространства.
- Формула: $u\in H^1(\Omega)$, $v\in H^1_0(\Omega)$ $\Rightarrow$ $\int uv_{x_j}\,dx=-\int u_{x_j}v\,dx$.
- Доказательство: для $v_k\in C_0^\infty$ — определение обобщённой производной, затем предельный переход $v_k\to v$ в $H^1_0$.
- Граничного члена нет — функции из $H^1_0$ «равны нулю на границе».
