# О-20. Пространство H1_0. Формула интегрирования по частям

> [!question] Формулировка билета
> Пространство $H^1_0(\Omega)$ и его свойства (гильбертово, сепарабельно). Формула интегрирования по частям.

**Где в конспекте:** ч. 1, лекция 6 (с. 47), лекция 7 (с. 50).

## Кратко (план ответа)
- $H^1_0(\Omega)$ — замыкание $C_0^\infty(\Omega)$ в норме $H^1$; замкнутое подпространство гильбертова сепарабельного пространства.
- Формула: $u\in H^1(\Omega)$, $v\in H^1_0(\Omega)$ $\Rightarrow$ $\int uv_{x_j}\,dx=-\int u_{x_j}v\,dx$.
- Доказательство: для $v_k\in C_0^\infty$ — определение обобщённой производной, затем предельный переход $v_k\to v$ в $H^1_0$.
- Граничного члена нет — функции из $H^1_0$ «равны нулю на границе».

---

## Определение
**Определение 6.18.** $H^1_0(\Omega)$ — замыкание $C_0^\infty(\Omega)$ в норме $H^1(\Omega)$. Иначе: $u\in H^1_0(\Omega)$ $\iff$ существуют $u_m\in C_0^\infty(\Omega)$ с $\|u_m-u\|_{H^1(\Omega)}\to0$.

## Свойства
**Замечание 6.6.** $H^1_0(\Omega)\subset H^1(\Omega)$ — **замкнутое подпространство** гильбертова пространства, поэтому само **гильбертово** (замкнутое подмножество полного пространства полно) и **сепарабельно** (подпространство сепарабельного).

$H^1_0\ne H^1$ для ограниченной $\Omega$: $u\equiv1\in H^1$, но $1\notin H^1_0$ — следует из [[О-21 Неравенство Фридрихса|неравенства Фридрихса]]. Смысл: функции из $H^1_0$ «равны нулю на границе» (их след на $\partial\Omega$ нулевой, [[О-26 След функции из H1_0|О-26]]).

На $H^1_0(\Omega)$ (при ограниченной $\Omega$) можно ввести эквивалентное скалярное произведение
$$(u,v)_{H^1_0(\Omega)}=\int_\Omega\nabla u\cdot\nabla v\,dx,\qquad\|u\|_{H^1_0}=\|\nabla u\|_{L_2}\qquad(7.4),(7.5)$$
— эквивалентность норм даёт неравенство Фридрихса.

## Формула интегрирования по частям
**Утверждение (формула 7.1).** Пусть $\Omega$ — ограниченная область, $u\in H^1(\Omega)$, $v\in H^1_0(\Omega)$. Тогда
$$\int_\Omega u\,v_{x_j}\,dx=-\int_\Omega u_{x_j}\,v\,dx .\qquad(7.1)$$

*Доказательство.* Пусть $v_k\in C_0^\infty(\Omega)$, $\|v_k-v\|_{H^1(\Omega)}\to0$. По определению обобщённой производной функции $u$ (с пробной функцией $v_k$)
$$\int_\Omega u\,(v_k)_{x_j}dx=-\int_\Omega u_{x_j}v_k\,dx .$$
Переходим к пределу при $k\to\infty$:
$$\Bigl|\int u\,(v_k-v)_{x_j}\Bigr|\le\|u\|_{L_2}\|(v_k-v)_{x_j}\|_{L_2}\to0,\qquad\Bigl|\int u_{x_j}(v_k-v)\Bigr|\le\|u_{x_j}\|_{L_2}\|v_k-v\|_{L_2}\to0 .$$
Получаем (7.1). $\square$

**Следствие.** Для $u\in H^1(\Omega)$, $v\in H^1_0(\Omega)$ и $w\in H^1$ с $\Delta$-подобными комбинациями формулы Грина работают без граничных членов; в частности, если $u\in C^2(\overline\Omega)$, то $\int_\Omega\nabla u\nabla v=-\int_\Omega\Delta u\,v$ для всех $v\in H^1_0$ (применить (7.1) к $u_{x_j}\in H^1$ и просуммировать).
