# О-06. Пример С.В. Ковалевской

> [!question] Формулировка билета
> Пример С.В. Ковалевской.

**Где в конспекте:** ч. 1, лекция 3 (с. 21).

## Что рассказывать
- Задача Коши для уравнения теплопроводности $u_t=u_{xx}$, $u(x,0)=\dfrac{1}{1-x}$.
- Формальный степенной ряд по $t$ имеет нулевой радиус сходимости.
- Вывод: условие теоремы (данные на нехарактеристической поверхности, уравнение разрешено относительно старшей производной по нормальному направлению) существенно — прямая $t=0$ для этого уравнения характеристическая.
