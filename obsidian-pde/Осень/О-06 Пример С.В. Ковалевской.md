# О-06. Пример С.В. Ковалевской

> [!question] Формулировка билета
> Пример С.В. Ковалевской.

**Где в конспекте:** ч. 1, лекция 3 (с. 21).

## Кратко (план ответа)
- Задача Коши для уравнения теплопроводности $u_t=u_{xx}$, $u(x,0)=\dfrac{1}{1+x^2}$.
- Формальный степенной ряд по $t$ имеет нулевой радиус сходимости.
- Вывод: условие теоремы (данные на нехарактеристической поверхности, уравнение разрешено относительно старшей производной по нормальному направлению) существенно — прямая $t=0$ для этого уравнения характеристическая.

---

## Смысл примера
Теорема Коши–Ковалевской требует, чтобы уравнение было записано в **нормальной форме** (2.1) — разрешено относительно старшей производной по направлению, трансверсальному к поверхности данных (поверхность нехарактеристическая). Пример С.В. Ковалевской показывает, что без этого условия аналитического решения может не быть даже при аналитических данных.

## Пример
Задача Коши для уравнения теплопроводности:
$$u_t=u_{xx},\qquad u|_{t=0}=\frac1{1+x^2}.\qquad(3.2)$$
Данные аналитичны в нуле: $\frac1{1+x^2}=\sum_{k\ge0}(-1)^kx^{2k}$ при $|x|<1$.

Прямая $t=0$ — **характеристика**: старшая часть $-u_{xx}$, для $F=t$ имеем $\nabla F=(1,0)$ (по переменным $(t,x)$) и $(A\nabla F,\nabla F)=a^{tt}=0$. Кроме того, уравнение первого порядка по $t$, а не второго.

## Доказательство отсутствия аналитического решения
Пусть существует аналитическое в $(0,0)$ решение
$$u(x,t)=\sum_{\alpha_1,\alpha_2}h_{\alpha_1,\alpha_2}t^{\alpha_1}x^{\alpha_2}.\qquad(3.3)$$
1. **Начальное условие.** При $t=0$: $\sum_{\alpha_2}h_{0,\alpha_2}x^{\alpha_2}=\sum_k(-1)^kx^{2k}$, откуда $h_{0,2k}=(-1)^k$, $h_{0,2k-1}=0$.
2. **Рекуррентное соотношение.** Коэффициент при $t^{m-1}x^p$ в $u_t$ равен $m\,h_{m,p}$, в $u_{xx}$ — $(p+2)(p+1)h_{m-1,p+2}$. Из уравнения
$$h_{m,p}=h_{m-1,p+2}\frac{(p+1)(p+2)}m .$$
3. **Решение рекурсии.** Отсюда $h_{m,2k-1}=0$, а
$$h_{m,2k}=h_{m-1,2k+2}\frac{(2k+1)(2k+2)}m=\dots=h_{0,2k+2m}\frac{(2k+1)\cdots(2k+2m)}{m!}=(-1)^{k+m}\frac{(2k+2m)!}{(2k)!\,m!}.$$
4. **Расходимость.** Значит, если решение существует, то $u(0,t)=\sum_m(-1)^m\dfrac{(2m)!}{m!}t^m$. Радиус сходимости этого ряда
$$R=\lim_{m\to\infty}\Bigl|\frac{a_m}{a_{m+1}}\Bigr|=\lim_{m\to\infty}\frac{(2m)!\,(m+1)!}{m!\,(2m+2)!}=\lim\frac{m+1}{(2m+1)(2m+2)}=0 .$$
Ряд расходится при любом $t\ne0$ — противоречие с аналитичностью. $\square$

## Вывод
Условие «уравнение в нормальной форме относительно нехарактеристической поверхности» в теореме Коши–Ковалевской существенно. Для уравнения теплопроводности задача Коши ставится в другом классе — ограниченных функций (весенний семестр, [[В-26 Задача Коши для однородного уравнения теплопроводности|В-26]]).
