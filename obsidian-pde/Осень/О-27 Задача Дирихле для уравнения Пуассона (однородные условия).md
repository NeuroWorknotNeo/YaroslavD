# О-27. Задача Дирихле для уравнения Пуассона (однородные условия)

> [!question] Формулировка билета
> Задача Дирихле для уравнения Пуассона с однородными краевыми условиями. Определение классического и обобщенного решения. Теорема существования и единственности обобщенного решения однородной задачи Дирихле.

**Где в конспекте:** ч. 1, лекция 8 (с. 60–61).

## Кратко (план ответа)
- $-\Delta u=f$ в $\Omega$, $u=0$ на $\partial\Omega$; классическое решение $u\in C^2(\Omega)\cap C(\overline\Omega)$.
- Классическое решение удовлетворяет $\int\nabla u\nabla\varphi=\int f\varphi$ для $\varphi\in H^1_0$ (интегрирование по частям + предельный переход).
- Обобщённое решение: $u\in H^1_0$, $(u,\varphi)_{H^1_0}=(f,\varphi)_{L_2}$ для всех $\varphi\in H^1_0$.
- Теорема Рисса: $l(\psi)=\int f\psi$ ограничен ($|l(\psi)|\le C\|f\|_{L_2}\|\psi\|_{H^1_0}$ по Фридрихсу) $\Rightarrow$ существует единственное решение, $\|u\|_{H^1_0}\le C\|f\|_{L_2}$.

---

## Постановка
**Задача Дирихле для уравнения Пуассона с однородными краевыми условиями:**
$$-\Delta u=f,\ x\in\Omega;\qquad u=0,\ x\in\partial\Omega,\qquad(8.1)$$
$\Omega$ — ограниченная область, $f$ — заданная функция.

**Определение 8.19.** **Классическое решение** (8.1) — функция $u\in C^2(\Omega)\cap C(\overline\Omega)$, такая что $u|_{\partial\Omega}=0$ и уравнение выполнено в каждой точке $\Omega$ (предполагается $f\in C(\Omega)$).

## Интегральное тождество
**Утверждение.** Если $u\in C^2(\overline\Omega)$ — классическое решение (8.1) и $f\in C(\overline\Omega)$, то
$$\int_\Omega\nabla u\cdot\nabla\phi\,dx=\int_\Omega f\phi\,dx\qquad\forall\phi\in H^1_0(\Omega).\qquad(8.2)$$

*Доказательство.* Для $\phi\in C_0^\infty(\Omega)$: $-\int_\Omega\Delta u\,\phi=\int_\Omega f\phi$. [[Многомерное интегрирование по частям]] (первая формула Грина):
$$\int_\Omega\nabla u\nabla\phi\,dx-\int_{\partial\Omega}\partial_\nu u\,\phi\,ds=\int_\Omega f\phi\,dx,\qquad(8.3)$$
и граничный интеграл равен нулю, так как $\phi=0$ на $\partial\Omega$. Для $\phi\in H^1_0$ берём $\phi_m\in C_0^\infty(\Omega)$, $\|\phi_m-\phi\|_{H^1}\to0$, и переходим к пределу в $\int\nabla u\nabla\phi_m=\int f\phi_m$ (обе части непрерывны по $\phi$ в норме $H^1$). $\square$

## Обобщённое решение
**Определение 8.20.** Функция $u\in H^1_0(\Omega)$ — **обобщённое (слабое) решение** задачи (8.1), $f\in L_2(\Omega)$, если
$$(u,\phi)_{H^1_0(\Omega)}=(f,\phi)_{L_2(\Omega)}\qquad\forall\phi\in H^1_0(\Omega),\qquad(8.4)$$
где $(u,\phi)_{H^1_0}=\int_\Omega\nabla u\nabla\phi\,dx$ (скалярное произведение (7.4)). Граничное условие заложено в требование $u\in H^1_0$; классическое решение из $C^2(\overline\Omega)$ — обобщённое.

## Теорема существования и единственности
**Теорема 8.16.** Задача (8.1) имеет единственное обобщённое решение $u\in H^1_0(\Omega)$, и
$$\|u\|_{H^1_0(\Omega)}\le C\|f\|_{L_2(\Omega)} .\qquad(8.5)$$

*Доказательство.* Используем [[Теорема Рисса|теорему Рисса]]: если $l:H\to\mathbb R$ — линейный ограниченный функционал на гильбертовом пространстве $H$, то существует единственный $h\in H$ с $l(z)=(h,z)_H$ для всех $z\in H$, и $\|h\|_H=\|l\|$.

1. $H=H^1_0(\Omega)$ со скалярным произведением $\int\nabla u\nabla v$ — гильбертово пространство (это скалярное произведение эквивалентно исходному по [[О-21 Неравенство Фридрихса|неравенству Фридрихса]]).
2. Функционал $l(\psi)=\int_\Omega f\psi\,dx$ линеен и ограничен: по Коши–Буняковскому и Фридрихсу
$$|l(\psi)|\le\|f\|_{L_2}\|\psi\|_{L_2}\le C(\Omega)\|f\|_{L_2}\|\psi\|_{H^1_0(\Omega)} .\qquad(8.6)$$
3. По теореме Рисса существует единственный $u\in H^1_0$ с $(u,\psi)_{H^1_0}=l(\psi)$ для всех $\psi$ — это и есть (8.4).
4. Оценка: $\|u\|_{H^1_0}=\|l\|\le C(\Omega)\|f\|_{L_2}$ (или: положить $\psi=u$ в (8.4) и применить (8.6): $\|u\|^2_{H^1_0}\le C\|f\|\|u\|_{H^1_0}$). $\square$

## Замечания
- Единственность можно увидеть и напрямую: разность $w$ двух решений удовлетворяет $(w,\phi)_{H^1_0}=0$ для всех $\phi$; при $\phi=w$ получаем $\|\nabla w\|=0$, и по Фридрихсу $w=0$.
- Другой путь к той же теореме — вариационный метод ([[О-32 Вариационный метод. Минимум функционала|О-32]]).
