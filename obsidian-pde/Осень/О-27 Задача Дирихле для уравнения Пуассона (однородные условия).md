# О-27. Задача Дирихле для уравнения Пуассона (однородные условия)

> [!question] Формулировка билета
> Задача Дирихле для уравнения Пуассона с однородными краевыми условиями. Определение классического и обобщенного решения. Теорема существования и единственности обобщенного решения однородной задачи Дирихле.

**Где в конспекте:** ч. 1, лекция 8 (с. 60–61).

## Что рассказывать
- $-\Delta u=f$ в $\Omega$, $u=0$ на $\partial\Omega$; классическое решение $u\in C^2(\Omega)\cap C(\overline\Omega)$.
- Классическое решение удовлетворяет $\int\nabla u\nabla\varphi=\int f\varphi$ для $\varphi\in H^1_0$ (интегрирование по частям + предельный переход).
- Обобщённое решение: $u\in H^1_0$, $(u,\varphi)_{H^1_0}=(f,\varphi)_{L_2}$ для всех $\varphi\in H^1_0$.
- Теорема Рисса: $l(\psi)=\int f\psi$ ограничен ($|l(\psi)|\le C\|f\|_{L_2}\|\psi\|_{H^1_0}$ по Фридрихсу) $\Rightarrow$ существует единственное решение, $\|u\|_{H^1_0}\le C\|f\|_{L_2}$.
