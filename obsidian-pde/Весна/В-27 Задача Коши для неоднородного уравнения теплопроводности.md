# В-27. Задача Коши для неоднородного уравнения теплопроводности

> [!question] Формулировка билета
> Решение задачи Коши для неоднородного уравнения теплопроводности в классе ограниченных функций.

**Где в конспекте:** ч. 2, лекция 11 (с. 67–70).

## Что рассказывать
- Принцип Дюамеля: $u=\int_0^tU(x,t,s)\,ds$, $U(\cdot,\cdot,s)$ решает однородное уравнение с $U|_{t=s}=f(\cdot,s)$.
- Явная формула через фундаментальное решение; дифференцирование под знаком интеграла после замены $y=x+2\sqrt{t-s}\,\eta$ и интегрирования по частям.

## Методы доказательства
- [[Принцип Дюамеля]] — построение решения
- [[Фундаментальное решение и потенциалы]] — явная формула
