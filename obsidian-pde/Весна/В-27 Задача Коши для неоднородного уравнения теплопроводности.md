# В-27. Задача Коши для неоднородного уравнения теплопроводности

> [!question] Формулировка билета
> Решение задачи Коши для неоднородного уравнения теплопроводности в классе ограниченных функций.

**Где в конспекте:** ч. 2, лекция 11 (с. 67–70).

## Кратко (план ответа)
- Принцип Дюамеля: $u=\int_0^tU(x,t,s)\,ds$, $U(\cdot,\cdot,s)$ решает однородное уравнение с $U|_{t=s}=f(\cdot,s)$.
- Явная формула через фундаментальное решение; дифференцирование под знаком интеграла после замены $y=x+2\sqrt{t-s}\,\eta$ и интегрирования по частям.

---

## Постановка
$$Tu=f(x,t)\ \text{в }G_\tau,\qquad u|_{t=0}=0 .\qquad(11.3)$$
Сумма решения (11.3) и решения однородной задачи с данными $u_0$ ([[В-26 Задача Коши для однородного уравнения теплопроводности|В-26]]) решает общую задачу $Tu=f$, $u|_{t=0}=u_0$ (11.4).

## Теорема
**Теорема 37.** Пусть $f$, $f_{x_j}$ ($j=1,\dots,n$) непрерывны в $\overline{G_\tau}$ и ограничены: $|f|,|f_{x_j}|\le C$. Тогда ограниченным решением задачи (11.3) класса $C^{2,1}(G_\tau)\cap C(\overline{G_\tau})$ является
$$u(x,t)=\int_0^t\frac1{(2\sqrt{\pi(t-s)})^n}\int_{\mathbb R^n}f(y,s)e^{-\frac{|x-y|^2}{4(t-s)}}dy\,ds .\qquad(11.5)$$

*Доказательство.* **Ограниченность и начальное условие.** Так как $\int\Gamma\,dy=1$,
$$|u(x,t)|\le C\int_0^t\frac1{(2\sqrt{\pi(t-s)})^n}\int e^{-\frac{|x-y|^2}{4(t-s)}}dy\,ds=Ct\le C\tau,$$
и $u(x,t)\to0$ при $t\to0$.

**Удобная запись.** Замена $y=x+2\sqrt{t-s}\,\eta$, $dy=(2\sqrt{t-s})^nd\eta$:
$$u(x,t)=\int_0^t\pi^{-n/2}\int_{\mathbb R^n}f\bigl(x+2\sqrt{t-s}\,\eta,s\bigr)e^{-|\eta|^2}d\eta\,ds .$$
**Первые производные по $x$.** Интеграл с $f_{x_j}$ сходится равномерно, поэтому
$$u_{x_j}=\int_0^t\pi^{-n/2}\int f_{x_j}(x+2\sqrt{t-s}\eta,s)e^{-|\eta|^2}d\eta\,ds .$$
Так как $\partial_{\eta_j}f(x+2\sqrt{t-s}\eta,s)=2\sqrt{t-s}\,f_{x_j}$, интегрируя по частям по $\eta_j$ (внеинтегральные члены исчезают из-за $e^{-|\eta|^2}$):
$$u_{x_j}=\int_0^t\frac{\pi^{-n/2}}{2\sqrt{t-s}}\int e^{-|\eta|^2}\partial_{\eta_j}f\,d\eta\,ds=\int_0^t\frac{\pi^{-n/2}}{\sqrt{t-s}}\int\eta_je^{-|\eta|^2}f(x+2\sqrt{t-s}\eta,s)\,d\eta\,ds .$$
**Вторые производные.** Дифференцируя последнюю запись по $x_j$ (особенность $(t-s)^{-1/2}$ интегрируема, интеграл сходится равномерно):
$$u_{x_jx_j}=\int_0^t\pi^{-n/2}\int f_{x_j}(x+2\sqrt{t-s}\eta,s)\frac{\eta_j}{\sqrt{t-s}}e^{-|\eta|^2}d\eta\,ds .$$
**Производная по $t$** (верхний предел и подынтегральная функция):
$$u_t=\pi^{-n/2}\int f(x,t)e^{-|\eta|^2}d\eta+\sum_{j=1}^n\int_0^t\pi^{-n/2}\int f_{x_j}(x+2\sqrt{t-s}\eta,s)\frac{\eta_j}{\sqrt{t-s}}e^{-|\eta|^2}d\eta\,ds=f(x,t)+\sum_ju_{x_jx_j}.$$
Итак, $Tu=u_t-\Delta u=f$. $\square$

## Принцип Дюамеля
Формулу (11.5) можно записать как
$$u(x,t)=\int_0^tU(x,t,s)\,ds,\qquad U(x,t,s)=\frac1{(2\sqrt{\pi(t-s)})^n}\int_{\mathbb R^n}f(y,s)e^{-\frac{|x-y|^2}{4(t-s)}}dy,\qquad(11.6)$$
где $U(\cdot,\cdot,s)$ — решение **однородной** задачи со «стартом» в момент $s$: $TU=0$ при $t>s$, $U|_{t=s}=f(\cdot,s)$. Решение неоднородной задачи — суперпозиция решений однородных задач, «включаемых» в каждый момент $s$ (тот же [[Принцип Дюамеля|принцип]], что для волнового уравнения, [[О-12 Неоднородное волновое уравнение. Принцип Дюамеля|О-12]]).

Единственность ограниченного решения — теорема 33 ([[В-26 Задача Коши для однородного уравнения теплопроводности|В-26]]).
