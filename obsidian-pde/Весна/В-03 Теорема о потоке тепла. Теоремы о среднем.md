# В-03. Теорема о потоке тепла. Теоремы о среднем

> [!question] Формулировка билета
> Теорема о потоке тепла. Теоремы о среднем для гармонической функции.

**Где в конспекте:** ч. 2, лекция 1 (с. 9–11).

## Кратко (план ответа)
- Поток: $u$ гармонична $\Rightarrow$ $\int_{\partial\Omega'}\partial_\nu u\,ds=\int_{\Omega'}\Delta u\,dx=0$ (формула Стокса).
- Среднее по сфере: из представления тремя потенциалами в шаре слагаемое с $\partial_\nu u$ исчезает по теореме о потоке $\Rightarrow$ $u(x_0)=\dfrac1{|S_R|}\int_{S_R}u\,ds$.
- Среднее по шару — интегрированием по радиусу.

---

## Теорема о потоке тепла
**Теорема.** Пусть $u$ гармонична в $\Omega$, $\Omega'$ — подобласть с липшицевой границей, $\overline{\Omega'}\subset\Omega$. Тогда
$$\int_{\partial\Omega'}\frac{\partial u}{\partial\nu}\,ds=0 .$$
*Доказательство.* [[Формула Стокса]] с полем $A=\nabla u\in C^1(\overline{\Omega'})$: $\int_{\partial\Omega'}\partial_\nu u\,ds=\int_{\Omega'}\operatorname{div}\nabla u\,dx=\int_{\Omega'}\Delta u\,dx=0$. $\square$

Физически: в стационарном тепловом поле без источников суммарный поток тепла через любую замкнутую поверхность равен нулю. (Если $u\in C^1(\overline\Omega)$, то и $\int_{\partial\Omega}\partial_\nu u=0$ — необходимое условие разрешимости задачи Неймана.)

## Теорема о среднем по сфере
**Теорема 1.** Пусть $u\in C^2(T_R^{x_0})\cap C(\overline{T_R^{x_0}})$ гармонична в шаре $T_R^{x_0}$. Тогда
$$u(x_0)=\frac1{|S_R^{x_0}|}\int_{S_R^{x_0}}u(x)\,ds .\qquad(1.12)$$
*Доказательство.* Пусть $\rho<R$; тогда $u\in C^2(\overline{T_\rho^{x_0}})$, и по формуле представления (замечание 1 в [[В-02 Представление функции тремя потенциалами|В-02]])
$$u(x_0)=\int_{S_\rho^{x_0}}u\,\partial_\nu E\,ds-\int_{S_\rho^{x_0}}E\,\partial_\nu u\,ds .$$
На сфере $E=\frac{\rho^{2-n}}{(2-n)\omega_n}$ — константа, поэтому по теореме о потоке
$$\int_{S_\rho}E\,\partial_\nu u\,ds=\frac{\rho^{2-n}}{(2-n)\omega_n}\int_{S_\rho}\partial_\nu u\,ds=0 .$$
Далее $\partial_\nu E|_{S_\rho}=\frac1{(2-n)\omega_n}(r^{2-n})'|_{r=\rho}=\frac1{\omega_n\rho^{n-1}}$ (нормаль внешняя). Итак, $u(x_0)=\frac1{\omega_n\rho^{n-1}}\int_{S_\rho}u\,ds$, и предельный переход $\rho\to R$ (непрерывность $u$ на замкнутом шаре) даёт (1.12). $\square$

## Теорема о среднем по шару
**Теорема 2.** При тех же условиях
$$u(x_0)=\frac1{|T_R^{x_0}|}\int_{T_R^{x_0}}u(x)\,dx .\qquad(1.13)$$
*Доказательство.* По теореме 1 $u(x_0)\,\omega_n\rho^{n-1}=\int_{S_\rho^{x_0}}u\,ds$ для $\rho\le R$. Интегрируем по $\rho\in[0,R]$:
$$u(x_0)\int_0^R\omega_n\rho^{n-1}d\rho=\int_0^R\int_{S_\rho}u\,ds\,d\rho\quad\Longleftrightarrow\quad u(x_0)|T_R^{x_0}|=\int_{T_R^{x_0}}u\,dx .\ \square$$

## Третья теорема о среднем (с весом)
**Теорема 3.** Пусть $\phi\in C[0,R]$, $A_\phi=\int_{T_R^{x_0}}\phi(|x-x_0|)dx\ne0$, $u$ гармонична в шаре и непрерывна в замкнутом шаре. Тогда
$$u(x_0)=A_\phi^{-1}\int_{T_R^{x_0}}u(x)\,\phi(|x-x_0|)\,dx .\qquad(1.14)$$
*Доказательство.* Умножим $u(x_0)\omega_n\rho^{n-1}=\int_{S_\rho}u\,ds$ на $\phi(\rho)$ и проинтегрируем по $\rho$: $u(x_0)\int_0^R\omega_n\rho^{n-1}\phi(\rho)d\rho=\int_{T_R}u\,\phi(|x-x_0|)dx$, а левый интеграл равен $A_\phi$. $\square$

## Следствие: бесконечная гладкость
**Теорема 4.** Гармоническая в $\Omega$ функция бесконечно дифференцируема.
*Доказательство.* Пусть $\overline{T_h^x}\subset\Omega$. Для ядра усреднения $w_h(|x-y|)$ по теореме 3 (вес $\phi=w_h$, $A_\phi=1$)
$$u_h(x)=\int_{|x-y|<h}w_h(|x-y|)u(y)dy=u(x).$$
Но $u_h\in C^\infty$, значит, и $u\in C^\infty$ в $\Omega$. $\square$

Применения: оценки производных, Лиувилль, принцип максимума, Харнак — см. связанные билеты.
