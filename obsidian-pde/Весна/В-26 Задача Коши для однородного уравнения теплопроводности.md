# В-26. Задача Коши для однородного уравнения теплопроводности

> [!question] Формулировка билета
> Решение задачи Коши для однородного уравнения теплопроводности в классе ограниченных функций. Единственность решения в классе ограниченных функций.

**Где в конспекте:** ч. 2, лекции 10–11 (с. 60–66).

## Что рассказывать
- Интеграл Пуассона: $u(x,t)=\dfrac1{(2\sqrt{\pi t})^n}\int u_0(y)e^{-|x-y|^2/(4t)}dy$ — ограниченное решение при ограниченной непрерывной $u_0$.
- Единственность в классе ограниченных функций — принцип максимума в слое.
- Бесконечная скорость распространения тепла: при $u_0\ge0$, $u_0\not\equiv0$ получаем $u>0$ всюду при $t>0$.
