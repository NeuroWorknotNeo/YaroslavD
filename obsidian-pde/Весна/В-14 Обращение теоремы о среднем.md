# В-14. Обращение теоремы о среднем

> [!question] Формулировка билета
> Обращение теоремы о среднем.

**Где в конспекте:** ч. 2, лекция 4 (с. 25).

## Кратко (план ответа)
- Если $u\in C(\Omega)$ и для любого шара $u(x_0)$ равно среднему по шару (сфере), то $u$ гармонична.
- Доказательство: решаем задачу Дирихле в шаре с данными $u$, разность удовлетворяет свойству среднего $\Rightarrow$ принцип максимума $\Rightarrow$ разность ноль.

---

## Формулировка
**Теорема 10.** Пусть $u\in C(\Omega)$, и для любого шара $T_R^{x_0}$ с $\overline{T_R^{x_0}}\subset\Omega$
$$u(x_0)=\frac1{|T_R^{x_0}|}\int_{T_R^{x_0}}u(x)\,dx .$$
Тогда $u$ — гармоническая функция в $\Omega$.

## Доказательство
Зафиксируем шар с $\overline{T_R^{x_0}}\subset\Omega$ и решим задачу Дирихле
$$\Delta v=0\ \text{в }T_R^{x_0},\qquad v=u\ \text{на }S_R^{x_0}$$
(она разрешима для непрерывных данных: [[В-13 Задача Дирихле в шаре|В-13]] или интеграл Пуассона [[В-18 Функция Грина для шара. Интеграл Пуассона|В-18]]). Покажем, что $u\equiv v$ в шаре — тогда $u$ гармонична в нём, а значит, и во всей $\Omega$.

Функция $w=v-u$ непрерывна на $\overline{T_R^{x_0}}$, равна нулю на $S_R^{x_0}$ и обладает свойством среднего по шару для всех шаров внутри $T_R^{x_0}$ ($v$ — по теореме о среднем для гармонических функций, $u$ — по условию). Пусть $\max_{\overline{T_R}}w=M>0$; он достигается во внутренней точке (на границе $w=0$). По [[В-09 Строгий принцип максимума|сильному принципу максимума]] (его доказательство использует только свойство среднего по шару) $w\equiv M$ в $T_R^{x_0}$, а тогда по непрерывности $w=M>0$ и на границе — противоречие. Значит, $w\le0$; аналогично (для $-w$) $w\ge0$. Итак, $u=v$ в шаре. $\square$

## Замечания
- Вместе с теоремой о среднем ([[В-03 Теорема о потоке тепла. Теоремы о среднем|В-03]]) получаем **характеризацию**: непрерывная функция гармонична $\iff$ она обладает свойством среднего по шарам (или по сферам).
- Отсюда снова: равномерный предел гармонических функций гармоничен (свойство среднего сохраняется при равномерной сходимости).
- Другой критерий гармоничности — лемма Вейля ([[В-12 Лемма Вейля. Последовательности гармонических функций|В-12]]).
