# В-32. Фундаментальное решение оператора теплопроводности

> [!question] Формулировка билета
> Фундаментальное решение оператора теплопроводности. Свойства фундаментального решения.

**Где в конспекте:** ч. 2, лекция 11 (с. 69–70).

## Что рассказывать
- $\Gamma(x,x_0,t,t_0)=\dfrac{\theta(t-t_0)}{(2\sqrt{\pi(t-t_0)})^n}e^{-|x-x_0|^2/(4(t-t_0))}$.
- $T\Gamma=\delta$: $(\Gamma,T^*\varphi)=\varphi(x_0,t_0)$ для финитных $\varphi$, $T^*=-\partial_t-\Delta$.
- Свойства: $\int\Gamma\,dx=1$, $\Gamma\to\delta$ при $t\to t_0+$, гладкость вне полюса, нет аналитичности по $t$.
