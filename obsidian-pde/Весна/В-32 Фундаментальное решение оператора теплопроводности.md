# В-32. Фундаментальное решение оператора теплопроводности

> [!question] Формулировка билета
> Фундаментальное решение оператора теплопроводности. Свойства фундаментального решения.

**Где в конспекте:** ч. 2, лекция 11 (с. 69–70).

## Кратко (план ответа)
- $\Gamma(x,x_0,t,t_0)=\dfrac{\theta(t-t_0)}{(2\sqrt{\pi(t-t_0)})^n}e^{-|x-x_0|^2/(4(t-t_0))}$.
- $T\Gamma=\delta$: $(\Gamma,T^*\varphi)=\varphi(x_0,t_0)$ для финитных $\varphi$, $T^*=-\partial_t-\Delta$.
- Свойства: $\int\Gamma\,dx=1$, $\Gamma\to\delta$ при $t\to t_0+$, гладкость вне полюса, нет аналитичности по $t$.

---

## Определение
**Фундаментальное решение оператора теплопроводности** $T=\partial_t-\Delta$:
$$\Gamma(x,x_0,t,t_0)=\frac{\theta(t-t_0)}{\bigl(2\sqrt{\pi(t-t_0)}\bigr)^n}e^{-\frac{|x-x_0|^2}{4(t-t_0)}},\qquad(10.5)$$
$\theta$ — функция Хевисайда ($\theta(s)=1$ при $s>0$, $0$ при $s<0$); $(x_0,t_0)$ — **полюс**. Интеграл Пуассона — свёртка $u_0$ с $\Gamma$.

## Свойства
**1. Нормировка.** При $t>t_0$: $\int_{\mathbb R^n}\Gamma\,dx=1$. Для $n=1$, $x_0=0$, $t_0=0$: $\Gamma_0(x,t)=\frac1{2\sqrt{\pi t}}e^{-x^2/4t}$ — плотность нормального распределения с дисперсией $2t$; замена $x=2\sqrt t\eta$:
$$\int_{-\infty}^{+\infty}\frac1{2\sqrt{\pi t}}e^{-\frac{x^2}{4t}}dx=\int\pi^{-1/2}e^{-\eta^2}d\eta=1 .\qquad(10.6)$$
Для $n>1$ $\Gamma(x,0,t,0)=\Gamma_0(x_1,t)\cdots\Gamma_0(x_n,t)$, и интеграл — произведение одномерных.

**2. $T\Gamma=0$ при $t\ne t_0$.** Для $n=1$, $t>0$:
$$\partial_t\Gamma_0=-\frac1{2t}\Gamma_0+\frac{x^2}{4t^2}\Gamma_0,\qquad(\Gamma_0)_x=-\frac x{2t}\Gamma_0,\qquad(\Gamma_0)_{xx}=-\frac1{2t}\Gamma_0+\frac{x^2}{4t^2}\Gamma_0,$$
т.е. $T\Gamma_0=0$. Для $n>1$ по формуле для производной произведения $\partial_t\Gamma=\sum_k\prod_{j\ne k}\Gamma_0(x_j)\cdot\partial_t\Gamma_0(x_k)$, $\Delta\Gamma=\sum_k\prod_{j\ne k}\Gamma_0(x_j)\cdot\partial^2_{x_k}\Gamma_0(x_k)$, и $T\Gamma=0$. При $t<t_0$ $\Gamma\equiv0$. Сдвиг полюса не меняет уравнения.

**3. Гладкость.** $\Gamma\in C^\infty$ во всех точках, кроме полюса: при $x\ne x_0$ все производные стремятся к нулю при $t\to t_0+$ (экспонента подавляет степени $(t-t_0)^{-k}$). Но $\Gamma$ не аналитична по $t$ (обращается в нуль при $t<t_0$, не будучи нулём).

**4. $\Gamma\ge0$** и **$\Gamma\to\delta$ при $t\to t_0+$:** для непрерывной ограниченной $\phi$ $\int\Gamma(x,x_0,t,t_0)\phi(x)dx\to\phi(x_0)$ (как в доказательстве начального условия для интеграла Пуассона, [[В-26 Задача Коши для однородного уравнения теплопроводности|В-26]]).

**5. $\Gamma\in L_1^{loc}(\mathbb R^{n+1})$** (упражнение 8): $\Gamma\ge0$ и $\int_{t_0}^{t_0+A}\int_{\mathbb R^n}\Gamma\,dx\,dt=A$.

## $\Gamma$ — фундаментальное решение
Нужно доказать $T_{x,t}\Gamma(x,x_0,t,t_0)=\delta(x-x_0,t-t_0)$ (11.7), т.е.
$$(\Gamma,T^*\phi)=\phi(x_0,t_0)\qquad\forall\phi\in C_0^\infty(\mathbb R^{n+1}),\qquad T^*=-\partial_t-\Delta\qquad(11.8)$$
($T^*$ — формально сопряжённый оператор: $(T\phi,\psi)=(\phi,T^*\psi)$ для финитных функций).

*Доказательство.* Так как $\Gamma\in L_1^{loc}$ и $\Gamma=0$ при $t<t_0$,
$$(\Gamma,T^*\phi)=\int_{t_0}^{+\infty}\int_{\mathbb R^n}\Gamma(-\phi_t-\Delta\phi)\,dx\,dt=\lim_{\varepsilon\to0}\int_{t_0+\varepsilon}^{+\infty}\int_{\mathbb R^n}\Gamma(-\phi_t-\Delta\phi)\,dx\,dt .$$
При $t\ge t_0+\varepsilon$ функция $\Gamma$ гладкая. Интегрируя по частям по $t$ ($\phi$ финитна):
$$-\int_{t_0+\varepsilon}^\infty\int\Gamma\phi_t=\int_{t_0+\varepsilon}^\infty\int\partial_t\Gamma\,\phi+\int_{\mathbb R^n}\Gamma(x,x_0,t_0+\varepsilon,t_0)\phi(x,t_0+\varepsilon)dx,$$
а по $x$ (дважды, $\phi$ финитна): $-\int\Gamma\Delta\phi=-\int\Delta\Gamma\,\phi$. Так как $\partial_t\Gamma-\Delta\Gamma=0$ при $t>t_0$,
$$(\Gamma,T^*\phi)=\lim_{\varepsilon\to0}\int_{\mathbb R^n}\Gamma(x,x_0,t_0+\varepsilon,t_0)\,\phi(x,t_0+\varepsilon)\,dx .$$
По нормировке $\int\Gamma(x,x_0,t_0+\varepsilon,t_0)dx=1$, поэтому
$$\int\Gamma\phi(x,t_0+\varepsilon)dx-\phi(x_0,t_0)=\int\Gamma\bigl(\phi(x,t_0+\varepsilon)-\phi(x_0,t_0)\bigr)dx=\pi^{-n/2}\int e^{-|\eta|^2}\bigl(\phi(x_0+2\sqrt\varepsilon\eta,t_0+\varepsilon)-\phi(x_0,t_0)\bigr)d\eta\to0$$
(замена $x=x_0+2\sqrt\varepsilon\eta$; подынтегральная функция ограничена $2\max|\phi|e^{-|\eta|^2}$ и поточечно $\to0$ — теорема Лебега). Итак, $(\Gamma,T^*\phi)=\phi(x_0,t_0)$. $\square$

Это и есть [[Обобщённое интегрирование по частям|приём обобщённой постановки]]: равенство $T\Gamma=\delta$ понимается через перенос оператора на пробную функцию.

## Применения
Решение задачи Коши: однородной — $u=\int\Gamma(x,y,t,0)u_0(y)dy$ ([[В-26 Задача Коши для однородного уравнения теплопроводности|В-26]]), неоднородной — $u=\int_0^t\int\Gamma(x,y,t,s)f(y,s)dy\,ds$ ([[В-27 Задача Коши для неоднородного уравнения теплопроводности|В-27]]). Аналог фундаментального решения оператора Лапласа ([[В-01 Гармонические функции. Формулы Грина. Фундаментальное решение|В-01]]).
