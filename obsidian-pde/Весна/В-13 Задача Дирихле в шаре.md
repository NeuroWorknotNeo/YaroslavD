# В-13. Задача Дирихле в шаре

> [!question] Формулировка билета
> Разрешимость задачи Дирихле в шаре в классе полиномов. Теорема существования и единственности классического решения задачи Дирихле для уравнения Лапласа в шаре.

**Где в конспекте:** ч. 2, лекция 2 (с. 16–17).

## Кратко (план ответа)
- Для полиномиальных данных решение ищется полиномом: $\Delta$ — изоморфизм на подходящем подпространстве полиномов.
- Непрерывные данные приближаются полиномами (Вейерштрасс), решения сходятся равномерно по принципу максимума.
- Предел гармоничен (равномерный предел гармонических функций); единственность — принцип максимума.

---

## Постановка
$$\Delta u=0\ \text{в }T_1^0,\qquad u=\phi\ \text{на }S_1^0,\qquad\phi\in C(S_1^0).\qquad(2.8)$$
Ищем классическое решение $u\in C^2(T_1^0)\cap C(\overline{T_1^0})$ ($T_1^0$ — единичный шар с центром $0$).

**Единственность** следует из принципа максимума ([[В-08 Слабый принцип максимума|В-08]]).

## Шаг 1. Полиномиальные данные
Пусть $\mathscr P^m$ — пространство многочленов степени $\le m$ от $x\in\mathbb R^n$ (конечномерное).

**Лемма.** Для любого $p\in\mathscr P^m$ задача
$$\Delta w=p\ \text{в }T_1^0,\qquad w=0\ \text{на }S_1^0\qquad(2.10)$$
имеет единственное решение в классе многочленов.

*Доказательство.* Рассмотрим линейный оператор $T:\mathscr P^m\to\mathscr P^m$, $Tu=\Delta\bigl((1-|x|^2)u\bigr)$ (степень $(1-|x|^2)u$ не больше $m+2$, после $\Delta$ — не больше $m$). **$\ker T=\{0\}$:** если $Tu=0$, то $(1-|x|^2)u$ гармонична в шаре и равна нулю на $S_1^0$, по принципу максимума $(1-|x|^2)u\equiv0$ в $T_1^0$, значит, $u=0$ в шаре, а многочлен, равный нулю на открытом множестве, — нулевой. Оператор в конечномерном пространстве с нулевым ядром сюръективен: $\operatorname{Im}T=\mathscr P^m$. Итак, есть $u$ с $Tu=p$, и $w=(1-|x|^2)u$ решает (2.10). Единственность — принцип максимума. $\square$

**Следствие.** Для $q\in\mathscr P^m$ задача $\Delta u=0$ в $T_1^0$, $u=q$ на $S_1^0$ (2.9) имеет единственное полиномиальное решение: $u=q+w$, где $\Delta w=-\Delta q\in\mathscr P^{m-2}$, $w|_{S_1^0}=0$. Аналогично разрешима задача $\Delta u=p$, $u|_{S}=q$ (2.11).

## Шаг 2. Непрерывные данные
**Теорема.** Задача (2.8) с $\phi\in C(S_1^0)$ имеет единственное классическое решение.

*Доказательство.* По теореме Вейерштрасса (Стоуна–Вейерштрасса: многочлены разделяют точки сферы) существуют многочлены $q_k$ с $\max_{S_1^0}|\phi-q_k|\to0$. Пусть $u_k$ — полиномиальные решения задач $\Delta u_k=0$ в $T_1^0$, $u_k=q_k$ на $S_1^0$ (2.12). По принципу максимума
$$\max_{\overline{T_1^0}}|u_k-u_m|=\max_{S_1^0}|q_k-q_m|\to0,\quad k,m\to\infty .$$
Значит, $u_k$ сходятся равномерно на $\overline{T_1^0}$ к некоторой $u\in C(\overline{T_1^0})$, причём $u|_{S_1^0}=\lim q_k=\phi$. Предельная функция гармонична: $\int u_k\Delta\varphi=0$ для $\varphi\in C_0^\infty(T_1^0)$, при равномерной сходимости $\int u\Delta\varphi=0$, и по [[В-12 Лемма Вейля. Последовательности гармонических функций|лемме Вейля]] $u$ гармонична (в частности, $u\in C^\infty(T_1^0)$). Единственность — принцип максимума. $\square$

Для шара радиуса $R$ с центром $x_0$ — замена $x=x_0+Ry$. Явная формула решения — интеграл Пуассона ([[В-18 Функция Грина для шара. Интеграл Пуассона|В-18]]).
