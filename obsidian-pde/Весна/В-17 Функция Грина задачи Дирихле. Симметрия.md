# В-17. Функция Грина задачи Дирихле. Симметрия

> [!question] Формулировка билета
> Функция Грина задачи Дирихле для оператора Лапласа. Симметрия функции Грина.

**Где в конспекте:** ч. 2, лекция 3 (с. 19).

## Кратко (план ответа)
- $G(x,y)=E(x,y)+g(x,y)$, где $g$ гармонична по $x$ и $G|_{x\in\partial\Omega}=0$.
- Решение задачи Дирихле: $u(y)=\int_\Omega G\Delta u+\int_{\partial\Omega}u\,\partial_\nu G\,ds$ (из представления тремя потенциалами исчезает слагаемое с $\partial_\nu u$).
- Симметрия $G(x,y)=G(y,x)$: вторая формула Грина для $G(\cdot,y)$ и $G(\cdot,z)$ в области с вырезанными шариками.

---

## Мотивировка
Для $u\in C^2(\overline\Omega)$ и $x_0\in\Omega$ ([[В-02 Представление функции тремя потенциалами|В-02]])
$$u(x_0)=\int_\Omega\Delta u\,E(x,x_0)dx-\int_{\partial\Omega}E(x,x_0)\partial_\nu u\,ds+\int_{\partial\Omega}u\,\partial_\nu E(x,x_0)ds .\qquad(3.1)$$
Для задачи Дирихле
$$\Delta u=f\ \text{в }\Omega,\qquad u=\phi\ \text{на }\partial\Omega\qquad(3.2)$$
всё в (3.1) известно, кроме $\partial_\nu u$. Цель — подправить $E$ так, чтобы этот член исчез.

## Определение
Пусть для каждого $x_0\in\Omega$ решена задача
$$\Delta_xg(x,x_0)=0,\ x\in\Omega;\qquad g(x,x_0)\big|_{x\in\partial\Omega}=-E(x,x_0)\big|_{x\in\partial\Omega},\qquad(3.3)$$
и $g(\cdot,x_0)\in C^2(\overline\Omega)$. **Функция Грина** задачи Дирихле для оператора Лапласа:
$$G(x,x_0)=E(x,x_0)+g(x,x_0).\qquad(3.7)$$
Её свойства: $\Delta_xG=\delta(x-x_0)$ в $\Omega$ (гармонична по $x$ при $x\ne x_0$, с особенностью фундаментального решения), $G|_{x\in\partial\Omega}=0$. Функция Грина единственна (разность двух гармонична и равна нулю на границе).

## Формула решения
Вторая формула Грина для $u$ и $g(\cdot,x_0)$ в $\Omega$ (обе гладкие):
$$\int_\Omega(g\Delta u-u\Delta g)dx=\int_{\partial\Omega}(g\partial_\nu u-u\partial_\nu g)ds\ \Rightarrow\ 0=\int_\Omega fg\,dx-\int_{\partial\Omega}\phi\,\partial_\nu g\,ds+\int_{\partial\Omega}E\,\partial_\nu u\,ds\qquad(3.5)$$
(использовано $g=-E$ на $\partial\Omega$). Складывая с (3.1):
$$u(x_0)=\int_\Omega f(x)G(x,x_0)dx+\int_{\partial\Omega}\phi(x)\,\partial_{\nu(x)}G(x,x_0)\,ds .\qquad(3.6)$$
В частности, для $\Delta u=0$, $u|_{\partial\Omega}=\phi$: $u(x_0)=\int_{\partial\Omega}\phi\,\partial_\nu G(x,x_0)ds$ (3.10). (Это формула представления **если решение существует**; построение $G$ для шара — [[В-18 Функция Грина для шара. Интеграл Пуассона|В-18]].)

## Симметрия
**Утверждение (упражнение 4).** $G(x_0,x_1)=G(x_1,x_0)$ для всех $x_0\ne x_1$ из $\Omega$.

*Доказательство.* Пусть $u(x)=G(x,x_0)$, $v(x)=G(x,x_1)$, $\Omega_\varepsilon=\Omega\setminus(\overline{T_\varepsilon^{x_0}}\cup\overline{T_\varepsilon^{x_1}})$. В $\Omega_\varepsilon$ обе функции гармоничны и гладки, на $\partial\Omega$ равны нулю. Вторая формула Грина:
$$0=\int_{\Omega_\varepsilon}(u\Delta v-v\Delta u)=\int_{S_\varepsilon^{x_0}}(u\partial_\nu v-v\partial_\nu u)ds+\int_{S_\varepsilon^{x_1}}(u\partial_\nu v-v\partial_\nu u)ds,$$
нормали на малых сферах направлены к их центрам. Около $x_0$: $v$ гладкая, $u=E(\cdot,x_0)+g(\cdot,x_0)$. Как в выводе (1.8),
$$\int_{S_\varepsilon^{x_0}}u\,\partial_\nu v\to0\ \ (|E|\varepsilon^{n-1}\sim\varepsilon\to0),\qquad\int_{S_\varepsilon^{x_0}}v\,\partial_\nu u\to-v(x_0)\ \ \Bigl(\partial_\nu E=-\frac1{\omega_n\varepsilon^{n-1}}\Bigr).$$
Значит, интеграл по $S_\varepsilon^{x_0}$ стремится к $v(x_0)=G(x_0,x_1)$. Около $x_1$ — симметрично: $\int_{S^{x_1}_\varepsilon}u\partial_\nu v\to-u(x_1)$, $\int v\partial_\nu u\to0$, т.е. интеграл стремится к $-u(x_1)=-G(x_1,x_0)$. В пределе $0=G(x_0,x_1)-G(x_1,x_0)$. $\square$

**Следствие.** $G(x,x_0)$ гармонична и по $x_0$ при $x_0\ne x$; поэтому, например, $\partial_{\nu(x)}G(x,x_0)$ — гармоническая функция $x_0$, и интеграл (3.10) гармоничен по $x_0$.
