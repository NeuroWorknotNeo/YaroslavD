# В-17. Функция Грина задачи Дирихле. Симметрия

> [!question] Формулировка билета
> Функция Грина задачи Дирихле для оператора Лапласа. Симметрия функции Грина.

**Где в конспекте:** ч. 2, лекция 3 (с. 19).

## Что рассказывать
- $G(x,y)=E(x,y)+g(x,y)$, где $g$ гармонична по $x$ и $G|_{x\in\partial\Omega}=0$.
- Решение задачи Дирихле: $u(y)=\int_\Omega G\Delta u+\int_{\partial\Omega}u\,\partial_\nu G\,ds$ (из представления тремя потенциалами исчезает слагаемое с $\partial_\nu u$).
- Симметрия $G(x,y)=G(y,x)$: вторая формула Грина для $G(\cdot,y)$ и $G(\cdot,z)$ в области с вырезанными шариками.
