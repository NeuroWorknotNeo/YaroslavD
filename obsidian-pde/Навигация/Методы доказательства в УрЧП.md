# Методы доказательства в УрЧП

Почти каждое доказательство курса собирается из небольшого набора приёмов. Ниже — все приёмы, которые встречаются в билетах; у каждого есть своя заметка со списком билетов, где он нужен.

## Шесть ключевых методов

1. [[Формула Стокса]] — $\int_\Omega\operatorname{div}A\,dx=\int_{\partial\Omega}(A,\nu)\,ds$ — переносит интеграл по области на границу. *(билетов: 13)*
2. [[Многомерное интегрирование по частям]] — $\int_\Omega uv_{x_j}=-\int_\Omega u_{x_j}v+\int_{\partial\Omega}uv\nu_j$ для гладких функций; частный случай — формулы Грина. *(билетов: 9)*
3. [[Обобщённое интегрирование по частям]] — $\int_\Omega uv_{x_j}=-\int_\Omega u_{x_j}v$ для $u\in H^1(\Omega)$, $v\in H^1_0(\Omega)$ — без граничного члена. *(билетов: 8)*
4. [[Теорема Рисса]] — Линейный ограниченный функционал на гильбертовом пространстве представляется скалярным произведением: $l(z)=(h,z)_H$. *(билетов: 4)*
5. [[Неравенство Фридрихса]] — $\|u\|_{L_2(\Omega)}\le C(\Omega)\|\nabla u\|_{L_2(\Omega)}$ для $u\in H^1_0(\Omega)$ — норма градиента эквивалентна норме $H^1$ на $H^1_0$. *(билетов: 6)*
6. [[Неравенство Пуанкаре]] — $\int_{\Pi_a}u^2\le|\Pi_a|^{-1}(\int_{\Pi_a}u)^2+\frac n2\sum_j(2a_j)^2\int_{\Pi_a}u_{x_j}^2$ для $u\in H^1(\Pi_a)$ — норма через среднее и градиент. *(билетов: 2)*

### Как они связаны между собой

- [[Формула Стокса]] $\Rightarrow$ [[Многомерное интегрирование по частям]] (поле с одной компонентой $uv$) $\Rightarrow$ формулы Грина.
- [[Многомерное интегрирование по частям]] с финитной пробной функцией $\Rightarrow$ определение обобщённой производной $\Rightarrow$ [[Обобщённое интегрирование по частям]] (по плотности).
- [[Неравенство Фридрихса]] $\Rightarrow$ $\int\nabla u\nabla v$ — скалярное произведение на $H^1_0$ $\Rightarrow$ применима [[Теорема Рисса]].
- [[Неравенство Пуанкаре]] $\Rightarrow$ теорема Реллиха–Кондрашова $\Rightarrow$ спектр оператора Лапласа.
- Типовая схема билета про обобщённое решение: классическое решение $\to$ интегральное тождество (интегрирование по частям) $\to$ расширение по плотности (обобщённое интегрирование по частям) $\to$ существование (Рисс + Фридрихс).

## Остальные методы курса

- [[Энергетический метод]] — Умножить уравнение на $u_t$ или $u$, проинтегрировать, получить монотонную «энергию». *(билетов: 6)*
- [[Принцип максимума]] — Экстремум решения достигается на (параболической) границе; отсюда единственность, оценки, сравнение. *(билетов: 17)*
- [[Приближение гладкими функциями]] — Доказать для гладких функций и перейти к пределу: средние функции, плотность $C_0^\infty$. *(билетов: 9)*
- [[Метод мажорант]] — Сходимость степенного ряда решения доказывается сравнением с явно решаемой «мажорирующей» задачей. *(билетов: 4)*
- [[Принцип сжимающих отображений]] — Свести задачу к интегральному уравнению $u=\Phi(u)$ и показать, что $\Phi$ — сжатие. *(билетов: 1)*
- [[Принцип Дюамеля]] — Решение неоднородного уравнения — интеграл по $s$ от решений однородных задач со стартом в момент $s$. *(билетов: 3)*
- [[Метод сферических средних]] — Усреднение по сферам сводит волновое уравнение в $\mathbb R^3$ к одномерному; метод спуска даёт $n=2$ и $n=1$. *(билетов: 3)*
- [[Метод Фурье]] — Разложение решения по собственным функциям оператора Лапласа. *(билетов: 1)*
- [[Вариационный метод]] — Решение — минимум функционала энергии; минимизирующая последовательность сходится по тождеству параллелограмма. *(билетов: 2)*
- [[Фундаментальное решение и потенциалы]] — Решения строятся свёрткой с фундаментальным решением; функция Грина подправляет его под границу. *(билетов: 9)*
