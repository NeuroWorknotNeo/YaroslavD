# Энергетический метод

> [!abstract] Коротко
> Умножить уравнение на $u_t$ (волновое) или $u$ (теплопроводности), проинтегрировать по частям и получить монотонную «энергию».

## Схема
1. Умножить уравнение на подходящую функцию: $u_t$ для $u_{tt}-\Delta u=0$, $u$ для $u_t-\Delta u=0$.
2. Проинтегрировать по области (или по пространственно-временной области) и применить [[Многомерное интегрирование по частям]]: $u_tu_{tt}=\frac12(u_t^2)_t$, $u_t\Delta u=\operatorname{div}(u_t\nabla u)-\frac12(|\nabla u|^2)_t$, $u\Delta u=\operatorname{div}(u\nabla u)-|\nabla u|^2$.
3. Граничные члены исчезают (граничные условия) или имеют знак (боковая поверхность характеристического конуса).
4. Получаем монотонность энергии. Для разности двух решений начальная энергия равна нулю $\Rightarrow$ решения совпадают.

## Примеры из курса
**Волновое уравнение.** $E(t)=\int_{\Omega_t}(u_t^2+|\nabla u|^2)$ не возрастает в характеристическом конусе (ч. 1, теорема 3.2): граничный интеграл по боковой поверхности конуса имеет вид $\frac1{2\sqrt2}\int_\Gamma(u_t^2+|\nabla u|^2-2u_t(\nabla u,\tilde n))\ge0$ (так как $\ge(|u_t|-|\nabla u|)^2$). Следствия: единственность задачи Коши, область зависимости.

**Смешанная задача для волнового уравнения (обобщённые решения).** Пробная функция $v=\int_t^\tau w\,ds$ вместо $w_t$ (теорема 10.24): получается $\int w^2(x,\tau)+\int|\eta(x,0)|^2=0$.

**Уравнение теплопроводности.** $e(t)=\int_\Omega v^2$, $e'(t)=-2\int|\nabla v|^2\le0$ (теорема 27); априорная оценка в $L_2$ с неравенством $2ab\le\varepsilon a^2+\varepsilon^{-1}b^2$ (теорема 30); единственность в обратном времени через $(e')^2\le e\,e''$ и выпуклость $\ln e$ (теорема 29).

## Плюсы по сравнению с принципом максимума
Работает для второй краевой задачи, для систем, для обобщённых решений; даёт оценки в $L_2$/$H^1$, нужные для метода Фурье и Галёркина.
