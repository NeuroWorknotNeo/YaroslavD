# Энергетический метод

> [!abstract] Коротко
> Умножить уравнение на $u_t$ или $u$, проинтегрировать, получить монотонную «энергию».

## Идея
Умножаем уравнение на подходящую функцию ($u_t$ для волнового, $u$ для теплопроводности), интегрируем по области (по частям) и получаем величину («энергию»), которая не возрастает. Для разности двух решений энергия в начальный момент равна нулю — значит, ноль всегда.

## Примеры из курса
- **Волновое уравнение**: $E(t)=\int_{\Omega_t}(u_t^2+|\nabla u|^2)$ не возрастает в характеристическом конусе (ч. 1, с. 26–28) — использует [[Формула Стокса|формулу Стокса]] в $\mathbb R^{n+1}$.
- **Теплопроводность**: $e(t)=\int_\Omega v^2$, $e'(t)=-2\int|\nabla v|^2\le0$ (ч. 2, с. 45) — [[Многомерное интегрирование по частям]].
- **Обратное время**: $(e')^2\le e\,e''$, логарифмическая выпуклость (ч. 2, с. 47–48).
- **Априорные оценки** в $L_2$ для уравнения теплопроводности (ч. 2, с. 49–50) с неравенством $2ab\le\varepsilon a^2+\varepsilon^{-1}b^2$.
