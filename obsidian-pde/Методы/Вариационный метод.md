# Вариационный метод

> [!abstract] Коротко
> Решение — точка минимума функционала энергии; минимизирующая последовательность сходится по тождеству параллелограмма.

## Схема
1. **Функционал** $E(u)=\|u\|_H^2+2(f,u)_{L_2}$ на замкнутом $H\subset H^1(\Omega)$ с эквивалентной нормой.
2. **Ограниченность снизу:** $E(u)\ge(\|u\|_H-C\|f\|)^2-C^2\|f\|^2\ge-C^2\|f\|^2$ (Коши–Буняковский, [[Неравенство Фридрихса|Фридрихс]]); $d=\inf E$ конечно.
3. **Минимизирующая последовательность фундаментальна:** $\bigl\|\frac{v_m-v_s}2\bigr\|^2=\frac12E(v_m)+\frac12E(v_s)-E\bigl(\frac{v_m+v_s}2\bigr)\le\varepsilon$ (тождество параллелограмма); предел — точка минимума; единственность — тем же тождеством.
4. **Уравнение Эйлера:** $\frac d{dt}E(u+tv)\big|_{t=0}=0$ $\Rightarrow$ $(u,v)_H+(f,v)=0$ для всех $v\in H$ — интегральное тождество задачи Дирихле $\Delta u=f$, $u\in H^1_0$.
5. **Метод Ритца:** минимизация на $R_k=\langle\psi_1,\dots,\psi_k\rangle$ — линейная система с матрицей Грама; последовательность Ритца минимизирующая и сходится к решению.

## Смысл
Обобщённое решение задачи Дирихле — функция с минимальной «энергией» среди всех функций с данными граничными значениями. Это второе (наряду с [[Теорема Рисса|теоремой Рисса]]) доказательство существования и единственности и основа численных методов.
