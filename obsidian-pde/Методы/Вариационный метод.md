# Вариационный метод

> [!abstract] Коротко
> Решение — минимум функционала энергии; минимизирующая последовательность сходится по тождеству параллелограмма.

## Идея
$E(u)=\|u\|_H^2+2(f,u)_{L_2}$ ограничен снизу ([[Неравенство Фридрихса]]), минимизирующая последовательность фундаментальна, предел — единственный минимум. Уравнение Эйлера минимума — интегральное тождество задачи Дирихле. Метод Ритца — минимизация на конечномерных подпространствах.
