# Метод Фурье

> [!abstract] Коротко
> Разложение решения по собственным функциям оператора Лапласа; сходимость ряда — из ортогональности и оценок коэффициентов.

## Схема
1. **Базис.** Собственные функции задачи Дирихле $\Delta w_k=\lambda_kw_k$, $w_k\in H^1_0$, $0>\lambda_1\ge\lambda_2\ge\dots\to-\infty$: ортонормированный базис в $L_2(\Omega)$, ортогональный в $H^1_0$, $\|w_k\|^2_{H^1_0}=|\lambda_k|$ (теорема 9.22 + Гильберт–Шмидт).
2. **Разложение данных:** $u_0=\sum u_{0,k}w_k$, $\|u_0\|^2_{H^1_0}=\sum|\lambda_k|u_{0,k}^2$; $u_1=\sum u_{1,k}w_k$; $f=\sum f_k(t)w_k$, $\sum_k\int_0^Tf_k^2=\|f\|^2_{L_2(Q_T)}$.
3. **ОДУ для коэффициентов:** $u=\sum V_k(t)w_k$, $V_k''-\lambda_kV_k=f_k$, $V_k(0)=u_{0,k}$, $V_k'(0)=u_{1,k}$ — явная формула через $\cos\sqrt{|\lambda_k|}t$, $\sin\sqrt{|\lambda_k|}t$.
4. **Оценки:** $V_k^2|\lambda_k|$, $(V_k')^2\le3\bigl(|\lambda_k|u_{0,k}^2+u_{1,k}^2+T\int f_k^2\bigr)$ — хвосты сходящихся рядов.
5. **Сходимость** частичных сумм в $H^1(Q_T)$ и **предельный переход** в интегральном тождестве.

## Где
Существование обобщённого решения смешанной задачи для волнового уравнения (теорема 10.25); классическое решение задачи о струне при гладких согласованных данных; тот же базис — в методе Галёркина для уравнения теплопроводности.
