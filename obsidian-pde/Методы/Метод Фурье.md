# Метод Фурье

> [!abstract] Коротко
> Разложение решения по собственным функциям оператора Лапласа.

## Идея
$u=\sum T_k(t)w_k(x)$, где $-\Delta w_k=\lambda_kw_k$, $w_k|_{\partial\Omega}=0$. Для $T_k$ получаются ОДУ, сходимость ряда — из ортогональности и оценок коэффициентов.

## Где
Существование обобщённого решения начально-краевой задачи для волнового уравнения; метод Галёркина для теплопроводности использует тот же базис.
