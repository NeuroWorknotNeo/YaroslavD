# Обобщённое интегрирование по частям

> [!abstract] Коротко
> $\int_\Omega uv_{x_j}=-\int_\Omega u_{x_j}v$ для $u\in H^1(\Omega)$, $v\in H^1_0(\Omega)$ — без граничного члена.

## Формулировка (как в конспекте)

> **Формула интегрирования по частям** (ч. 1, лекция 7, с. 50, формула (7.1)). Пусть $\Omega$ — ограниченная область в $\mathbb R^n$, $u\in H^1(\Omega)$, $v\in H^1_0(\Omega)$. Тогда
> $$\int_\Omega u\,v_{x_j}\,dx=-\int_\Omega u_{x_j}\,v\,dx .$$

## Доказательство (по конспекту)
Пусть $v_k\in C_0^\infty(\Omega)$, $\|v_k-v\|_{H^1(\Omega)}\to0$ (так определено $H^1_0$). По **определению обобщённой производной**
$$\int_\Omega u\,(v_k)_{x_j}\,dx=-\int_\Omega u_{x_j}v_k\,dx .$$
Обе части непрерывны по $v_k$ в норме $H^1$ (неравенство Коши–Буняковского: $|\int u(v_k-v)_{x_j}|\le\|u\|_{L_2}\|v_k-v\|_{H^1}$), переходим к пределу при $k\to\infty$. $\square$

## Откуда «растут ноги»
- Само **определение обобщённой производной** (ч. 1, с. 44) — это интегрирование по частям с пробной функцией $\varphi\in C_0^\infty(\Omega)$:
  $$\int_\Omega u\,D^\alpha\varphi\,dx=(-1)^{|\alpha|}\int_\Omega v\,\varphi\,dx\quad\forall\varphi\in C_0^\infty(\Omega)\ \Longleftrightarrow\ v=D^\alpha u .$$
  Мотивировка — [[Формула Стокса]] для гладких функций (граничный член нулевой из-за финитности).
- Формула (7.1) расширяет класс пробных функций с $C_0^\infty$ до $H^1_0$ — **по плотности**.

## Общая схема «обобщённой» техники
1. Для гладких/классических объектов получаем тождество через [[Многомерное интегрирование по частям]] (граничный член пропадает, если пробная функция финитна).
2. Тождество, верное для всех $\varphi\in C_0^\infty$, по плотности переносим на $\varphi\in H^1_0$ (см. [[Приближение гладкими функциями]]).
3. Принимаем полученное тождество за **определение** обобщённого решения — оно имеет смысл и для негладких функций.

Так устроены: определение обобщённой производной, обобщённое решение задачи Дирихле $(u,\varphi)_{H^1_0}=(f,\varphi)_{L_2}$ (ч. 1, с. 60–61), обобщённое решение волнового уравнения и начально-краевой задачи (с. 39, 75–76), проверка $T\Gamma=\delta$ для фундаментального решения.

## Пример использования: интегральное тождество задачи Дирихле
Классическое решение $-\Delta u=f$, $u|_{\partial\Omega}=0$ удовлетворяет $\int\nabla u\nabla\varphi=\int f\varphi$ для $\varphi\in C_0^\infty$ (шаг 1), а затем — для всех $\varphi\in H^1_0$ (шаг 2): $\varphi_m\to\varphi$ в $H^1$, и обе части непрерывны.

## Важно
- Граничного члена **нет** только потому, что одна из функций в $H^1_0$. Для $u,v\in H^1(\Omega)$ общего вида формула неверна (граничный член остаётся и понимается через след).
- Нельзя переносить на функцию производную, которой у неё нет: в (7.1) требуется, чтобы обе функции имели обобщённые производные первого порядка в $L_2$.
