# Обобщённое интегрирование по частям

> [!abstract] Коротко
> $\int_\Omega uv_{x_j}=-\int_\Omega u_{x_j}v$ для $u\in H^1(\Omega)$, $v\in H^1_0(\Omega)$ — без граничного члена.

## Формулировка (как в конспекте)
> **Формула интегрирования по частям** (ч. 1, лекция 7, с. 50, формула (7.1)). Пусть $\Omega$ — ограниченная область в $\mathbb R^n$, $u\in H^1(\Omega)$, $v\in H^1_0(\Omega)$. Тогда для $j=1,\dots,n$
> $$\int_\Omega u\,v_{x_j}\,dx=-\int_\Omega u_{x_j}\,v\,dx .$$

## Определения, на которые опирается формула
- **Обобщённая производная** (опр. 6.16): $w_\alpha\in L_{2,loc}(\Omega)$ — это $D^\alpha u$, если $\int_\Omega w_\alpha\varphi\,dx=(-1)^{|\alpha|}\int_\Omega u\,D^\alpha\varphi\,dx$ для всех $\varphi\in C_0^\infty(\Omega)$.
- $H^1(\Omega)=\{u\in L_2:\ u_{x_j}\in L_2\}$, $\|u\|^2_{H^1}=\int(u^2+|\nabla u|^2)$; $H^1_0(\Omega)$ — замыкание $C_0^\infty(\Omega)$ в $H^1(\Omega)$.

Определение обобщённой производной — это уже формула (7.1) для $v\in C_0^\infty(\Omega)$. Формула (7.1) расширяет её на все $v\in H^1_0$.

## Доказательство (по конспекту)
Пусть $v_k\in C_0^\infty(\Omega)$, $\|v_k-v\|_{H^1(\Omega)}\to0$ (по определению $H^1_0$). По определению обобщённой производной $u_{x_j}$
$$\int_\Omega u\,(v_k)_{x_j}\,dx=-\int_\Omega u_{x_j}v_k\,dx .$$
Обе части непрерывны относительно сходимости $v_k\to v$ в $H^1$: по неравенству Коши–Буняковского
$$\Bigl|\int u\,(v_k-v)_{x_j}\Bigr|\le\|u\|_{L_2}\|v_k-v\|_{H^1}\to0,\qquad\Bigl|\int u_{x_j}(v_k-v)\Bigr|\le\|u_{x_j}\|_{L_2}\|v_k-v\|_{L_2}\to0 .$$
Переходя к пределу, получаем (7.1). $\square$

## Общая схема «обобщённой» техники
1. Для гладких объектов получаем тождество через [[Многомерное интегрирование по частям]]; граничный член исчезает, если пробная функция финитна.
2. Тождество, верное для всех $\varphi\in C_0^\infty$, переносим **по плотности** на $\varphi\in H^1_0$ — как в доказательстве выше (см. [[Приближение гладкими функциями]]).
3. Полученное тождество принимаем за **определение** обобщённого решения: оно имеет смысл и для негладких функций.

Так устроены: обобщённая производная (опр. 6.16), обобщённое решение задачи Дирихле $(u,\varphi)_{H^1_0}=(f,\varphi)_{L_2}$ (опр. 8.20, 8.22), обобщённое решение волнового уравнения (опр. 5.15) и смешанной задачи (опр. 10.26), собственные функции (опр. 9.24), фундаментальное решение $(\Gamma,T^*\varphi)=\varphi(x_0,t_0)$.

## Пример
Классическое решение $u\in C^2(\overline\Omega)$ задачи $-\Delta u=f$, $u|_{\partial\Omega}=0$: для $\varphi\in C_0^\infty$ $\int\nabla u\nabla\varphi=\int f\varphi$ (шаг 1). Для $\varphi\in H^1_0$ берём $\varphi_m\in C_0^\infty$, $\varphi_m\to\varphi$ в $H^1$: $\bigl|\int\nabla u\nabla(\varphi_m-\varphi)\bigr|\le\|\nabla u\|\|\varphi_m-\varphi\|_{H^1}\to0$, $\bigl|\int f(\varphi_m-\varphi)\bigr|\to0$ — тождество верно для всех $\varphi\in H^1_0$ (шаг 2).

## Важно
- Граничного члена нет только потому, что одна из функций лежит в $H^1_0$ (её след на $\partial\Omega$ равен нулю). Для $u,v\in H^1(\Omega)$ общего вида формула неверна: например, $u=v=x$ на $(0,1)$: $\int_0^1x\cdot1\,dx=\frac12\ne-\int_0^1x\,dx$.
- Обе функции должны иметь обобщённые производные первого порядка в $L_2$.
