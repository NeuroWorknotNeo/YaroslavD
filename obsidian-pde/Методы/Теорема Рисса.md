# Теорема Рисса

> [!abstract] Коротко
> Линейный ограниченный функционал на гильбертовом пространстве представляется скалярным произведением: $l(z)=(h,z)_H$.

## Формулировка (как в конспекте)

> **Теорема Рисса** (ч. 1, лекция 8, с. 61). Если $l:H\to\mathbb R$ — линейный ограниченный функционал на гильбертовом пространстве $H$, то существует единственный элемент $h\in H$ такой, что для любого $z\in H$
> $$l(z)=(h,z)_H .$$
> При этом $\|h\|_H=\|l\|$.

## Доказательство (кратко, на случай вопроса)
Если $l=0$, берём $h=0$. Иначе ядро $N=\ker l$ — замкнутое подпространство $\ne H$; возьмём $z_0\perp N$, $l(z_0)=1$. Для любого $z$ элемент $z-l(z)z_0\in N$, значит, $(z-l(z)z_0,z_0)=0$, откуда $l(z)=\bigl(\frac{z_0}{\|z_0\|^2},z\bigr)$. Единственность: если $(h_1-h_2,z)=0$ для всех $z$, то $h_1=h_2$.

## Схема применения к краевым задачам (запомнить!)
1. **Пространство.** $H=H^1_0(\Omega)$ со скалярным произведением $(u,v)_{H^1_0}=\int_\Omega\nabla u\nabla v\,dx$. Это действительно скалярное произведение, эквивалентное исходному, — по [[Неравенство Фридрихса|неравенству Фридрихса]].
2. **Тождество.** Записываем обобщённую постановку в виде $(u,\varphi)_{H^1_0}=l(\varphi)$ для всех $\varphi\in H^1_0$.
3. **Ограниченность $l$.** Коши–Буняковский + Фридрихс: для $l(\psi)=\int f\psi$
   $$|l(\psi)|\le\|f\|_{L_2}\|\psi\|_{L_2}\le C(\Omega)\|f\|_{L_2}\|\psi\|_{H^1_0}\qquad\text{(ч. 1, (8.6))}.$$
4. **Вывод.** По теореме Рисса решение существует, единственно и $\|u\|_{H^1_0}=\|l\|\le C\|f\|_{L_2}$ — сразу получаем и априорную оценку (8.5).

## Где используется
- **Однородная задача Дирихле** (теорема 8.16): $l(\psi)=\int_\Omega f\psi\,dx$.
- **Неоднородная задача Дирихле** (теорема 8.17): для $v=u-\psi\in H^1_0$ функционал $l(\varphi)=\int f\varphi-\int\nabla\psi\nabla\varphi$, оценка $|l(\varphi)|\le C(\|f\|_{L_2}+\|\psi\|_{H^1})\|\varphi\|_{H^1_0}$ (8.12).
- **Оператор $A$ в задаче на собственные значения** (ч. 1, с. 70): для $u\in L_2$ функционал $l_u(v)=\int uv$ ограничен на $H^1_0$, по Риссу $l_u(v)=(Au,v)_{H^1_0}$ — так строится $A:L_2\to H^1_0$ ($A=(-\Delta)^{-1}$ в обобщённом смысле).
- **Вариационный метод** — альтернативный путь к тем же результатам (минимизация $E(u)$ вместо Рисса).

## Что спрашивают
- *Почему $H^1_0$, а не $H^1$?* На $H^1$ форма $\int\nabla u\nabla v$ не является скалярным произведением (константы), а на $H^1_0$ является благодаря неравенству Фридрихса.
- *Откуда единственность?* Из единственности в теореме Рисса (или напрямую: разность двух решений ортогональна всему $H^1_0$).
