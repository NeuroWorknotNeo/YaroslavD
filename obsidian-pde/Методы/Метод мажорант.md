# Метод мажорант

> [!abstract] Коротко
> Сходимость степенного ряда решения доказывается сравнением с явно решаемой «мажорирующей» задачей.

## Идея
Коэффициенты Тейлора решения — многочлены с неотрицательными коэффициентами от коэффициентов задачи. Если заменить данные их мажорантами, коэффициенты решения только увеличатся по модулю. Подбираем мажорирующую задачу с явным сходящимся решением.

## Где
Доказательство теоремы Коши–Ковалевской (ч. 1, лекции 2–3).
