# Метод сферических средних

> [!abstract] Коротко
> Сферические средние решения удовлетворяют одномерному волновому уравнению — вывод формулы Кирхгофа; метод спуска даёт $n=2$, $n=1$.

## Сферическое среднее
$I(r,t)=\frac1{4\pi r^2}\int_{|\xi-x|=r}u(\xi,t)\,dS_\xi=\frac1{4\pi}\int_{|\eta|=1}u(x+r\eta,t)\,dS_\eta$; $I\to u(x,t)$ при $r\to0$.

**Ключевое тождество** (по [[Формула Стокса|формуле Стокса]] в шаре):
$$I_r=\frac1{4\pi r^2}\int_{|\xi-x|=r}\partial_\nu u\,dS=\frac1{4\pi r^2}\int_{|\xi-x|<r}\Delta u\,d\xi .$$
Если $u_{tt}=\Delta u$, то $(r^2I_r)_r=r^2I_{tt}$, т.е. $(rI)_{tt}=(rI)_{rr}$ — одномерное волновое уравнение для $rI$ с условием $rI|_{r=0}=0$.

## Вывод формулы Кирхгофа
Формула Даламбера с нечётным продолжением и предел $r\to0$ дают
$$u(x,t)=\partial_t\bigl(tI_0(t)\bigr)+tI_1(t)=\partial_tM[u_0]+M[u_1],\qquad M[g]=\frac1{4\pi t}\int_{|x-\xi|=t}g\,dS .$$
Проверка того, что формула даёт решение при $u_0\in C^3$, $u_1\in C^2$, — прямым дифференцированием $M[g]$ (формула $\partial_tM[g]=\frac1tM[g]+\frac1{4\pi t}\int_{|x-\xi|<t}\Delta g$).

## Метод спуска
Решение в $\mathbb R^2$ — решение в $\mathbb R^3$, не зависящее от $x_3$; интеграл по сфере проецируется на круг с весом $\frac t{\sqrt{t^2-|x-\xi|^2}}$ — формула Пуассона. Аналогично $n=1$ — формула Даламбера.
