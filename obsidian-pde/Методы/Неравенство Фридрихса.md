# Неравенство Фридрихса

> [!abstract] Коротко
> $\|u\|_{L_2(\Omega)}\le C(\Omega)\|\nabla u\|_{L_2(\Omega)}$ для $u\in H^1_0(\Omega)$ — норма градиента эквивалентна норме $H^1$ на $H^1_0$.

## Формулировка (как в конспекте)

> **Неравенство Фридрихса** (ч. 1, лекция 7, с. 50, формула (7.2)). Пусть $\Omega$ — ограниченная область, $u\in H^1_0(\Omega)$. Тогда
> $$\|u\|_{L_2(\Omega)}\le C(\Omega)\,\|\nabla u\|_{L_2(\Omega)} .$$

## Доказательство (по конспекту)
**Шаг 1: гладкие финитные функции.** Пусть $u\in C_0^\infty(\Omega)$, $\overline\Omega\subset\Pi_a=\{|x_j|<a_j\}$, $a_1=\min a_j$. Продолжим $u$ нулём на $\Pi_a\setminus\overline\Omega$. По формуле Ньютона–Лейбница
$$u(x)=\int_{-a_1}^{x_1}u_{y_1}(y_1,\hat x)\,dy_1,\qquad\hat x=(x_2,\dots,x_n).$$
Возводим в квадрат и применяем неравенство Коши–Буняковского:
$$u^2(x)\le(x_1+a_1)\int_{-a_1}^{a_1}u_{x_1}^2\,dx_1 .$$
Интегрируем по $\Pi_a$:
$$\int_\Omega u^2dx=\int_{\Pi_a}u^2dx\le2a_1^2\int_{\Pi_a}u_{x_1}^2dx\le2a_1^2\int_\Omega|\nabla u|^2dx.\qquad(7.3)$$
**Шаг 2: общий случай.** Для $u\in H^1_0(\Omega)$ берём $u_m\in C_0^\infty(\Omega)$, $u_m\to u$ в $H^1$; для $u_m$ верно (7.3), переходим к пределу. $\square$

Постоянная: $C(\Omega)=\sqrt2\,a_1$, где $a_1$ — полуширина объемлющего параллелепипеда по одному направлению (важна лишь ограниченность $\Omega$ в одном направлении).

## Следствия (конспект, с. 51)
- $H^1_0(\Omega)\ne H^1(\Omega)$: $u\equiv1\in H^1$, но для неё неравенство нарушено ($\nabla u=0$), значит, $1\notin H^1_0$.
- На $H^1_0(\Omega)$ можно ввести эквивалентное скалярное произведение и норму
  $$(u,v)_{H^1_0}=\int_\Omega\nabla u\nabla v\,dx,\qquad\|u\|_{H^1_0}=\|\nabla u\|_{L_2}\quad(7.4),(7.5).$$

## Где используется
- [[Теорема Рисса]] в задачах Дирихле: ограниченность $l(\psi)=\int f\psi$ — $|l(\psi)|\le\|f\|_{L_2}\|\psi\|_{L_2}\le C\|f\|_{L_2}\|\psi\|_{H^1_0}$.
- [[Вариационный метод]]: оценка снизу $E(u)\ge-C^2\|f\|^2_{L_2}$ (ч. 1, (8.14)).
- Собственные значения задачи Дирихле: $\lambda_1\ge1/C(\Omega)^2>0$ и ограниченность оператора $A$.
- **Та же техника** (Ньютон–Лейбниц по одной переменной + Коши–Буняковский) доказывает теорему о следе (ч. 1, с. 51–52, (7.6)–(7.7)).

## Сравнение с неравенством Пуанкаре
| | Фридрихс | Пуанкаре |
|---|---|---|
| Пространство | $H^1_0(\Omega)$ | $H^1(\Pi_a)$ |
| Нулевые граничные значения | нужны | не нужны |
| Цена | — | добавка $\lvert\Pi_a\rvert^{-1}(\int u)^2$ |
| Почему | константу нельзя: она не ноль на границе | константы убивает член со средним |

См. [[Неравенство Пуанкаре]].
