2. УПРАВЛЕНИЕ (клавиши 0-7, как в требованиях)
--------------------------------------------------------------------------------

    0 - циклически сменить номер приближаемой функции k (0 -> 1 -> ... -> 6 -> 0).
        Возмущение p при этом сбрасывается в 0.
    1 - циклически сменить набор отображаемых графиков (9 режимов):
            0: только f
            1: f и многочлен Ньютона                     (метод 1)
            2: f и сплайн Эрмита                         (метод 2)
            3: f и параболический сплайн                 (метод 3)
            4: f и все три приближения сразу
            5: погрешность метода Ньютона
            6: погрешность метода Эрмита
            7: погрешность параболического сплайна
            8: погрешности всех трёх методов сразу
    2 - увеличить масштаб: отрезок сжимается вдвое к середине [a,b] (s := s+1).
    3 - уменьшить масштаб: отрезок растягивается вдвое (s := s-1).
    4 - удвоить число точек интерполяции n.
    5 - уменьшить n вдвое.
    6 - увеличить возмущение: f(x_{n/2}) := f(x_{n/2}) + p*0.1*max|f|, p := p+1.
    7 - то же в обратную сторону, p := p-1.
    Ctrl+Q - выход.

Цвета графиков:
    красный   - сама функция f;
    синий     - метод 1 (многочлен Ньютона) и его погрешность;
    зелёный   - метод 2 (сплайн Эрмита) и его погрешность;
    сиреневый - метод 3 (параболический сплайн) и его погрешность.

Что выводится в окне (верхняя панель и строка состояния): номер k и формула
функции, текущее n, текущий масштаб s, текущее возмущение p и величина
max{|F|} по отображаемым графикам. То же значение max{|F|} печатается в
консоль при каждом пересчёте - как требует пункт 6(b) требований.

Масштабирование: по оси X отрезок [a/2^s, b/2^s] (точнее, отрезок, сжатый s
раз к середине [a,b]) растягивается на всю ширину области рисования, по оси
Y отрезок [F_min, F_max] по ВСЕМ отображаемым в данный момент графикам - на
всю высоту (с запасом 5%, чтобы линии не прилипали к краям). Масштабы по X и
по Y независимы. При изменении размера окна масштаб пересчитывается
(обработчик resizeEvent).

Многочленная аппроксимация (метод 1) при n > 50 не строится и не рисуется -
как того требует пункт 7(d). В этом случае в окне пишется
"метод 1: не строится (n > 50)".

--------------------------------------------------------------------------------
4. МЕТОД 1. ИНТЕРПОЛЯЦИОННАЯ ФОРМУЛА НЬЮТОНА (задача 1)
--------------------------------------------------------------------------------

Дано n узлов x_1 < x_2 < ... < x_n и значения f_1, ..., f_n. Ищем ОДИН
многочлен степени n-1, проходящий через все точки. Записываем его в форме
Ньютона:

    P(x) = a_1 + a_2 (x-x_1) + a_3 (x-x_1)(x-x_2) + ...
                            ... + a_n (x-x_1)...(x-x_{n-1}),

где коэффициенты - это разделённые разности:

    a_j = f[x_1, x_2, ..., x_j].

Разделённые разности считаются по рекуррентной формуле

    f[x_i] = f_i,
    f[x_i, ..., x_{i+j}] = ( f[x_{i+1},...,x_{i+j}] - f[x_i,...,x_{i+j-1}] )
                           / ( x_{i+j} - x_i ).

В программе таблица разделённых разностей считается "на месте": в массив
coeffs сначала кладутся значения f_i, затем j = 1, 2, ..., n-1 раз делается
проход СПРАВА НАЛЕВО

    for (i = n-1; i >= j; i--)
        coeffs[i] = (coeffs[i] - coeffs[i-1]) / (x[i] - x[i-j]);

Проход справа налево нужен для того, чтобы не затереть ещё не использованное
значение. После всех проходов coeffs[j] = f[x_1,...,x_{j+1}] - это и есть
нужные коэффициенты. Стоимость: O(n^2) действий, O(n) памяти.

Значение в точке считается по схеме Горнера (вложенными скобками):

    P(x) = a_1 + (x-x_1)( a_2 + (x-x_2)( a_3 + ... ) )

то есть за O(n) действий, без возведения в степень и без накопления
произведений (это устойчивее по погрешности округления).

Свойства метода:
  - многочлен степени n-1 точен на любом многочлене степени <= n-1;
  - на "хороших" функциях (e^x) сходимость очень быстрая;
  - на функции Рунге 1/(25x^2+1) при равномерной сетке возникает
    известный эффект Рунге: у концов отрезка погрешность растёт с ростом n.
    Это хорошо видно в программе: синий график начинает "болтаться" у краёв.
    Именно поэтому в требованиях многочленные методы запрещено строить
    при n > 50.


--------------------------------------------------------------------------------
5. МЕТОД 2. КУБИЧЕСКИЕ МНОГОЧЛЕНЫ ЭРМИТА, ЕСТЕСТВЕННЫЕ ГРАНИЧНЫЕ УСЛОВИЯ
   (задача 13)
--------------------------------------------------------------------------------

Идея. Вместо одного многочлена большой степени на каждом отрезке
[x_i, x_{i+1}] строится СВОЙ кубический многочлен. Чтобы куски склеились
гладко, в каждом узле задаётся не только значение f_i, но и значение
производной d_i; тогда на отрезке [x_i, x_{i+1}] кубический многочлен
определяется однозначно четырьмя условиями

    P_i(x_i) = f_i,   P_i(x_{i+1}) = f_{i+1},
    P_i'(x_i) = d_i,  P_i'(x_{i+1}) = d_{i+1}.

Если записать P_i(x) = c_0 + c_1 t + c_2 t^2 + c_3 t^3, где t = x - x_i,
h = x_{i+1} - x_i и Δ = (f_{i+1} - f_i)/h, то прямое решение этих четырёх
уравнений даёт

    c_0 = f_i,
    c_1 = d_i,
    c_2 = ( 3Δ - 2 d_i - d_{i+1} ) / h,
    c_3 = ( d_i + d_{i+1} - 2Δ ) / h^2.

Эти четыре числа для каждого из n-1 отрезков и хранятся в массиве
коэффициентов длины 4(n-1).

Откуда берутся d_i. Сами производные функции нам не даны (метод работает
только по табличным значениям), поэтому во ВНУТРЕННИХ узлах они считаются
по трём соседним значениям через разделённые разности:

    d_i = f[x_{i-1}, x_i] + f[x_i, x_{i+1}] - f[x_{i-1}, x_{i+1}],   i = 2..n-1.

На равномерной сетке эта формула превращается в привычную центральную
разность d_i = (f_{i+1} - f_{i-1}) / (2h) и точна на многочленах 2-й степени
(проверяется подстановкой f = x^2: получается ровно 2 x_i).

В граничных узлах x_1 и x_n соседей с одной стороны нет, формула не
применима - это и есть "недостающие граничные условия". По условию задачи 13
они берутся из ЕСТЕСТВЕННЫХ граничных условий, то есть из требования нулевой
второй производной на концах:

    P_1''(x_1) = 0    и    P_{n-1}''(x_n) = 0.

Распишем первое. P_1''(x_1) = 2 c_2 = 2(3Δ_1 - 2 d_1 - d_2)/h_1 = 0, откуда

    d_1 = ( 3Δ_1 - d_2 ) / 2,      Δ_1 = (f_2 - f_1)/(x_2 - x_1).

Аналогично на правом конце: P''(x_n) = 2c_2 + 6 c_3 h = (2 d_{n-1} + 4 d_n -
6 Δ_{n-1})/h_{n-1} = 0, откуда

    d_n = ( 3Δ_{n-1} - d_{n-1} ) / 2.

Поскольку d_2 и d_{n-1} уже посчитаны локально, никакой системы уравнений
решать не надо: d_1 и d_n получаются сразу. Поэтому построение стоит O(n)
действий, а вычисление значения в точке - O(log n) (двоичный поиск нужного
отрезка функцией std::upper_bound + схема Горнера).

Частный случай n = 2: обе естественные условия на одном отрезке заставляют
кубический многочлен выродиться в линейный, программа это обрабатывает
отдельно.

Свойства метода (важно для проверок из пункта 8 требований):
  - метод ТОЧЕН на многочленах степени 0 и 1 (см. таблицу в разделе 8);
  - на многочленах 2-й и 3-й степени он не точен: естественные условия
    принудительно обнуляют вторую производную на концах, а у параболы она
    не нуль. Это не ошибка реализации, а свойство самих естественных
    граничных условий;
  - внутри отрезка погрешность ведёт себя как O(h^3) (при удвоении n падает
    примерно в 8 раз), а в двух приграничных отрезках - как O(h^2)
    (падает в 4 раза). Поэтому при больших n, когда именно приграничная
    погрешность становится главной, наблюдаемое отношение равно 4,
    а не 8 (это видно в таблице для e^x в разделе 8).


--------------------------------------------------------------------------------
6. МЕТОД 3. ПАРАБОЛИЧЕСКИЕ СПЛАЙНЫ, ГРАНИЧНЫЕ УСЛОВИЯ ЭКСТРАПОЛЯЦИЕЙ
   (задача 46)
--------------------------------------------------------------------------------

Параболический (квадратичный) сплайн - это функция S(x), которая на каждом
куске является многочленом 2-й степени и глобально непрерывна вместе с
первой производной. Если бы точки склейки совпадали с узлами интерполяции,
задача была бы переопределена, поэтому классическая конструкция такая: точки
склейки берутся МЕЖДУ узлами (в серединах):

    ξ_1     = x_1 - (x_2 - x_1)/2,
    ξ_i     = (x_{i-1} + x_i)/2,        i = 2..n,
    ξ_{n+1} = x_n + (x_n - x_{n-1})/2.

Тогда на каждом отрезке [ξ_i, ξ_{i+1}] лежит ровно один узел x_i, и на нём
строится квадратный трёхчлен

    P_i(x) = c_0 + c_1 t + c_2 t^2,   t = x - ξ_i,

подчинённый трём условиям:

    P_i(ξ_i) = v_i,    P_i(x_i) = f_i,    P_i(ξ_{i+1}) = v_{i+1},

где v_i = S(ξ_i) - пока НЕИЗВЕСТНЫЕ значения сплайна в точках склейки
(их n+1 штука). Из этих трёх условий коэффициенты выражаются явно:

    h_i = x_i - ξ_i,   z_i = ξ_{i+1} - ξ_i,   u_i = ξ_{i+1} - x_i = z_i - h_i,
    p_i = (f_i - v_i)/h_i,     q_i = (v_{i+1} - v_i)/z_i,
    c_2 = (q_i - p_i)/u_i,     c_1 = p_i - c_2 h_i,     c_0 = v_i.

Непрерывность сплайна уже обеспечена (соседние куски в точке ξ_{i+1} дают
одно и то же значение v_{i+1}). Остаётся потребовать непрерывность ПЕРВОЙ
производной во внутренних точках склейки ξ_2, ..., ξ_n. Вычисляя
P_i'(ξ_{i+1}) и P_{i+1}'(ξ_{i+1}) и приравнивая их, после упрощений получаем
линейное уравнение относительно трёх соседних неизвестных v_i, v_{i+1},
v_{i+2}:

  [ z_L/(h_L u_L) - (2z_L - h_L)/(z_L u_L) ] v_i
+ [ (2z_L - h_L)/(z_L u_L) + z_R/(h_R u_R) - h_R/(z_R u_R) ] v_{i+1}
+ [ h_R/(z_R u_R) ] v_{i+2}
= z_L f_i/(h_L u_L) + z_R f_{i+1}/(h_R u_R),

где индекс L относится к левому куску (номер i), R - к правому (номер i+1).
На равномерной сетке (h = z/2, u = z/2) это уравнение превращается в
красивое

    v_i + 6 v_{i+1} + v_{i+2} = 4 ( f_i + f_{i+1} ),

что легко проверить вручную на константе, на линейной функции и на параболе -
все три случая выполняются точно.

Уравнений получилось n-1, а неизвестных n+1. Недостающие ДВА уравнения дают
граничные условия. В задаче 46 они берутся ЭКСТРАПОЛЯЦИЕЙ в приграничных
узлах: крайние точки склейки ξ_1 и ξ_{n+1} лежат вне отрезка [x_1, x_n],
поэтому значения сплайна в них задаются экстраполяцией интерполяционного
многочлена, построенного по трём ближайшим узлам:

    v_1     = P(ξ_1),     P - многочлен по (x_1,f_1), (x_2,f_2), (x_3,f_3);
    v_{n+1} = P(ξ_{n+1}), P - многочлен по трём последним узлам.

Многочлен пишется в форме Ньютона и считается в точке за несколько действий
(функция extrapolate_by_three_nodes). При n = 2 трёх узлов нет, и
экстраполяция делается линейно по двум узлам.

Получившаяся система - ТРЁХДИАГОНАЛЬНАЯ (в каждой строке не более трёх
соседних неизвестных), она решается методом прогонки:

    прямой ход:  alpha_0 = -c_0/b_0,  beta_0 = d_0/b_0,
                 denom_i = b_i + a_i * alpha_{i-1},
                 alpha_i = -c_i/denom_i,
                 beta_i  = (d_i - a_i beta_{i-1})/denom_i;
    обратный ход: v_N = beta_N,  v_i = alpha_i v_{i+1} + beta_i.

Матрица системы диагонально доминирующая (на равномерной сетке строка
1, 6, 1), поэтому прогонка устойчива и выбор главного элемента не нужен.
Коэффициенты строк вычисляются "на лету" прямо в прямом ходе, сама матрица
нигде не хранится; массив alpha временно размещается в выходном массиве
коэффициентов (в нём 3n элементов, а нужно n+1). Итог: построение - O(n)
действий и никакой лишней памяти.

Вычисление значения в точке: отрезок склейки [ξ_i, ξ_{i+1}] симметричен
относительно узла x_i, поэтому нужный кусок - тот, чей узел ближайший к
точке; ищется двоичным поиском по массиву узлов за O(log n), затем значение
считается по схеме Горнера. Массив ξ при вычислении значения не нужен -
левый конец куска восстанавливается по двум соседним узлам, поэтому
подпрограмма вычисления значения имеет ровно тот набор аргументов, который
требует пункт 5 требований.

Свойства метода:
  - точен на многочленах степени 0, 1 и 2 (квадратичная экстраполяция на
    концах сохраняет точность на параболах - в отличие от естественных
    граничных условий);
  - погрешность O(h^3): при удвоении n падает примерно в 8 раз, причём
    и внутри, и у границ отрезка (см. таблицы в разделе 8).


--------------------------------------------------------------------------------
7. ЧТО ПРОИСХОДИТ ПРИ НАЖАТИИ КЛАВИШ 4/5 И 6/7
--------------------------------------------------------------------------------

Клавиши 4/5 (число точек). n удваивается или уменьшается вдвое, массивы
перевыделяются, сетка и все три приближения строятся заново. Многочлен
Ньютона при n > 50 не строится вовсе (и память под него не выделяется).
Сверху стоит ограничение n <= 2*10^7, чтобы случайными нажатиями не
исчерпать оперативную память.

Клавиши 6/7 (возмущение). Значение в средней точке заменяется на
f(x_{n/2}) + p*0.1*max|f| (max|f| берётся по исходной функции на [a,b] и НЕ
пересчитывается при возмущении). Все приближения строятся уже по
возмущённым данным, а погрешность по-прежнему считается относительно
настоящей функции f - поэтому на графике сразу видно, как разные методы
реагируют на "ошибку измерения": многочлен Ньютона разносит возмущение по
всему отрезку, а оба кусочно-многочленных метода локализуют его в
нескольких соседних отрезках.

9. ЗАМЕЧАНИЕ ОБ ОДНОМ НЕОДНОЗНАЧНОМ МЕСТЕ
--------------------------------------------------------------------------------

В формулировке задачи 13 сказано, как определяются НЕДОСТАЮЩИЕ граничные
условия (естественные), но не сказано явно, какой формулой считать
производные во внутренних узлах. Здесь выбрана стандартная формула через
разделённые разности

    d_i = f[x_{i-1}, x_i] + f[x_i, x_{i+1}] - f[x_{i-1}, x_{i+1}],

которая на равномерной сетке (а программа строит именно равномерную сетку)
совпадает с центральной разностью (f_{i+1} - f_{i-1})/(2h). Если
преподаватель имеет в виду другую формулу для внутренних узлов, меняется
ровно один цикл в файле hermite_natural.cpp - вся остальная конструкция
(вывод d_1 и d_n из условий P''= 0, коэффициенты кусков, поиск отрезка)
остаётся прежней.
